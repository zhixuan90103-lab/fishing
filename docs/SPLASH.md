# 水花、水纹和涟漪

状态：已实现。水面对碰它的东西有三种反应，是三样物料，都不知道碰它的是什么：

- **水花**（第 3 到 5 节）：一个东西砸进水里或者破水而出，溅起一圈水冠和水珠。摆在水面上方。它原来还自己画两道扩开的圈，2026-11-25 拿掉了，圈现在是水面自己起的。
- **水纹**（第 8 节）：一个东西贴着水面走，甩起水珠。摆在水面上方。
- **涟漪**（第 9 节）：水面自己的起伏。砸一下是一圈圈扩开的圆；走着的东西身后是两条斜臂的尾迹；水下的东西头顶是低而宽的缓涌。

水花由玩法报一下（饵落水、鱼出水），同一下也起涟漪。水纹和尾迹没有人触发：东西走得快就有，停了自己散。水面本身见 [ENGINEERING.md](./ENGINEERING.md) 第 6 节，谁在什么时候碰水见 [PLAY.md](./PLAY.md)。

## 1. 分层

| 文件 | 回答什么 |
|---|---|
| `src/shore/splashBurst.js` | 一次水花随时间的形状：水冠、中间的水柱多高多宽，每颗水珠在哪、多大、什么时候落回去。不引 Three，可以在 Node 里跑 |
| `src/shore/splash.js` | 把它们画出来，记着每一处已经过了多久，水珠落回水面时报一下 |

数据只往一个方向走：调用的人给位置和力度 → `splash` 记时间 → 每帧问 `splashBurst` 现在是什么形状 → 摆模型。

## 2. 不能破的规则

**不改海面的样子。** 水面外观已定（[AGENTS.md](../AGENTS.md) 硬性约定第 9 条），外观指的是样式和颜色（2026-11-25 说明）：浪、雾、粗糙、曝光、太阳、反射。水花和水纹是放在海面上方的几何体。涟漪（第 9 节）是唯一写进水面的东西：它只给水面加一份高度和倾斜，颜色和光照的算法一行不改。

**半透明的东西要在水面之后画。** 主场景先画，水面后画，盖在已有的东西上。半透明的东西如果放在主场景里，它先和海底混在一起，再在水面上留下一个洞。所以水花不加进主场景，加进 `startShore.js` 里那个在水面之后画的场景 `onWater`。它测深度、不写深度：竿仍然能挡住它，它不挡别的东西。以后落在水面上的半透明的东西（涟漪、泡沫）都放这个场景。

**形状是时间的函数，不积分。** 每颗水珠的位置、每一圈的半径都由"落水后过了多久"直接算出来。所以各帧率下一样，放完以后不占任何计算。

## 3. 形状（`splashBurst.js`）

三种水花。

**东西砸进水里（`in`）**，照真的落水顺序走四步：

1. **水冠**：砸下去的一瞬间，四周一圈薄水被掀起来，边缘甩出水珠，四分之一秒落回去。
2. **中间的水柱**：东西身后的坑合上，合上的地方正中间弹起一根水柱。它比水冠晚 0.09 秒，比水冠高一倍半。
3. **柱顶甩出水珠**：水柱翻过顶的时候，顶上断出三颗水珠。
4. **水珠落回去**：每颗落下的地方砸出一个小涟漪（由水面自己起，第 9 节）。

**东西被提出水面（`out`）**，不是砸：

1. **带起来的一堆水**：低而宽，半秒落回去。没有水冠。
2. **往下淌的一串水珠**：东西一边升一边滴，后滴的从更高处落下，四分之三秒里陆续落回水面，其中五颗各砸一个小涟漪。

**鱼在水面扑腾（`thrash`）**，既不是砸进去也不是提出来，是尾巴和身侧把水甩出去：

1. **一片薄水**：低，贴着水面往外飞，六分之一秒里从 8 厘米宽飞到 34 厘米宽，就没了。
2. **碎成一大片小水珠四溅**：二十六颗，朝各个方向，飞得低、飞得远，不往上蹿。比落水的水珠小一半。

没有中间的水柱，也没有带起的那堆水。它大小随力度和重量涨得慢（按平方根）：水珠本来就甩得快，再按整倍放大，大鱼最重的一下会溅到 0.7 米高、2.7 米远。

- **形状是时间的函数，不积分。** 所以各帧率下一样。
- **多大跟着力度和重量走**，和涟漪用同一个规律：重一百倍大两倍多，最多 2.4 倍。
- **每种水花是同一个转了不同的角度**，水珠的表各只生成一次。

量到的（Node）：

| 大鱼出水 | 没有 | 9 厘米（那一堆水） | 37 厘米 |

## 4. 画（`splash.js`、`sprayMaterial.js`）

- 水冠是一圈带锯齿边的薄片，水柱是一根上细下粗的圆锥。放在 `onWater` 场景里（第 2 节）。
- **水珠画成顺着飞行方向拉长的一道**，飞得越快越长（`DROP_LONG`、`STREAKS`），不是圆球。圆球加亮边看着就是泡泡。
- **同时可以有四处**（`AT_ONCE`）。再多，最老的让位。
- 水珠落回水面时它报一下：在哪、多重。它不知道有涟漪这回事，是 `startShore` 把这一下接到涟漪上的。每颗按 1 克、力度 0.14 算（`DROP_KG`、`DROP_HITS`），是一个巴掌大的小圈。
- 远处的画得稍大，见第 3 节。

**溅起来的水长什么样**（`sprayMaterial.js`，水花和水纹的水珠共用这一个材质）。空中的水是透明的，看得见的是它反回来的光：

- **正对着看**，大半是它后面的东西，略灰略蓝，很透（不透明度 0.22）。
- **边缘**，斜着看过去的地方，反的是天，很亮（不透明度 0.9）。
- 所以一片水是亮边、淡心；立起来的薄片几乎整片是亮的。
- **水珠是另一种画法**：它太小，画不出"亮边淡心"，那样画出来是个泡泡。水珠整颗是一点亮光（中间也有七成半实，`SPECK`）。
- **朝上的一面被天照着，朝下的一面暗**（剩五成半）。
- 原来是一种平的半透明白，像贴在水面上的纸。

| 常量（`sprayMaterial.js`） | 值 | 管什么 |
|---|---|---|
| `GLINT` | 略过白（1.5 上下） | 边缘反的天光多亮。后期的曝光不到 1，所以定在白以上 |
| `BODY`、`UNDER` | 灰蓝（0.42、0.58、0.66）、0.55 | 正对着看的颜色；朝下的一面剩几成 |
| `THIN`、`EDGE` | 0.22、0.9 | 正对着多透、边缘多实。嫌太淡调大 `THIN`，嫌太白调小 `EDGE` 或 `GLINT` |
| `RIM` | 1.6 | 亮边多窄。调大更窄 |

| 常量（`splash.js`） | 值 | 管什么 |
|---|---|---|
| `FADE_OVER` | 最后六成 | 从什么时候开始淡 |
| `DROP_LONG`、`STREAKS` | 1.4、每米每秒再加 0.9 | 水珠画成多长：不动时多长，飞得越快拉得越长 |
| `AT_ONCE` | 4 | 同时几处 |

## 5. 给玩法留的口子

`createSplash(落回水面时叫谁)` 返回的对象上有：

| 接口 | 作用 |
|---|---|
| `object` | 加在水面之后画的那个场景里，不是主场景。见第 2 节 |
| `burst(x, z, 力度, 重量)` | 东西在这一点砸进水里。力度 0 到 1 |
| `breach(x, z, 力度, 重量)` | 东西在这一点被提出水面 |
| `thrash(x, z, 力度, 重量)` | 鱼在这一点的水面扑腾，把水甩出去 |
| `seenFrom(位置)` | 从哪里看它，世界坐标。用来决定远处放大多少。`startShore` 每帧给镜头的位置 |
| `update(dt)` | 每帧一次 |
| `active` | 还有没放完的 |

玩法不直接拿它，拿的是 `startShore` 交的 `surface`（第 9.6 节）：`burst`、`breach`、`thrash` 同时叫水花和涟漪，`stir` 只叫涟漪。什么东西落水、落得多重算多大的力度，由玩法定，见 [PLAY.md](./PLAY.md)。

## 8. 水纹（`wakeTrack.js`、`wake.js`）

一个东西贴着水面走，走得够快就甩起几颗水珠，往两侧和后面抛。它也是尾迹（第 9 节）的来源：它读出这个东西多快、往哪走、多深，每隔一小会儿叫人在水面上留一段。

**没有人打开它。** 它只读被带着走的那个点：点走得多快，它就多强。低于 `QUIET` 没有，到 `FULL` 最强；点停了，它按 `DIES` 自己散掉。

| 文件 | 回答什么 |
|---|---|
| `src/shore/wakeTrack.js` | 这个点多快、往哪走、多深，纹多强，每颗水珠在哪，什么时候该在水面上再留一段。不引 Three，可以在 Node 里跑 |
| `src/shore/wake.js` | 把水珠画出来：一组实例化的小球。放在 `onWater` 场景里，规矩同第 2 节 |
| `src/shore/waterTop.js` | 一个东西在这个深度算不算在水面上，有多少还在水里。不引 Three |

- **速度不是两帧的差。** 一个点追着位置走，落后多远就是多快。各帧率下读数一样，位置抖一下也不会闪。
- **水珠按走过的路程甩，不按时间。** 速度过了 `SPRAY_ABOVE` 才有，每走一米甩 `DROPS_A_METRE` 颗（按纹的强弱打折），抛物线落回水面就没了。水珠是这里唯一积分的东西，寿命不到半秒。
- **水珠只有贴着水面的东西才甩。** 离水面 4 厘米以内全有，14 厘米以下没有；高出水面 5 厘米也没有（`waterTop.js`）。
- **`share`**：这个东西使了几成劲，0 到 1。线是 1；鱼由玩法给（[PLAY.md](./PLAY.md) 第 8 节）。**多深**也由带着它的人给：水面下多远，负的是高出水面多少。

现在有三个，只有鱼的那个画水珠：

| 谁 | 谁带着它 | 画水珠 |
|---|---|---|
| 钩住的鱼 | 玩法（`catch.js` 的 `churn.follow`），交鱼嘴的位置、几成劲、鱼背多深、多重 | 画，画成 1.6 倍大，同时最多 64 颗 |
| 线入水的那一点 | `startShore`，交 `line.entry` | 不画 |
| 水下拖着的饵 | 玩法（`fishing.js` 的 `wash.follow`），饵在水里、没有鱼时交饵的位置和深度 | 不画 |

| 常量（`wakeTrack.js`） | 值 | 管什么 |
|---|---|---|
| `TRAIL` | 9 /秒 | 读速度的那个点跟多紧。读到的速度大约是 1/9 秒前的 |
| `QUIET`、`FULL` | 0.3、2.4 米/秒 | 多快才有纹，多快最强 |
| `COMES`、`DIES` | 7、2.5 /秒 | 纹起来多快、散掉多快 |
| `SPRAY_ABOVE`、`DROPS_A_METRE` | 1.1 米/秒、14 | 多快才带水珠，每米几颗 |
| `DROP_UP`、`DROP_OUT`、`DROP_LIFE` | 0.5 到 1.4 米/秒、1.7 米/秒、0.42 秒 | 水珠向上、向两侧的初速，最多活多久 |
| `HITS_ABOVE` | 0.03 | 纹弱过这个，不在水面上留东西 |

| 常量（`waterTop.js`） | 值 | 管什么 |
|---|---|---|
| `TOP`、`DEEP` | 0.04、0.14 米 | 离水面多近算全在水面上，多深算完全不在 |
| `OUT` | 0.05 米 | 高出水面多少就算离开了水 |

| 常量（`wake.js`） | 值 | 管什么 |
|---|---|---|
| `DROP`、`DROP_LONG`、`STREAKS` | 0.012 米、1.4、0.9 | 水珠多大、画成多长。长什么样是 `sprayMaterial.js` 的（第 4 节） |

口子：`createWake(画多大, 水珠数, 留尾迹)` 返回 `object`、`track`、`update()`、`dispose()`。`track`（也可以单独用 `createWakeTrack(水珠数, random, 留尾迹)` 建一个不画的）有 `follow(dt, x, z, 几成, 多深)`，在水里时每帧一次；`lift(dt)`，不在水里时每帧一次。"留尾迹"是 `{ every, hit(track) }`：它带着纹、又在水里的时候，每 `every` 秒叫一次 `hit`。不给就不留。

试过不要的：

- 拖在后面的 V 形纹，画成两条直带子（2026-11-19）。现在的尾迹是水面自己的起伏。
- 线入水点也甩水珠（到 2026-11-25）。线入水点总比鱼近几米，两处水珠一上一下，看着像同一样东西在两个高度。
- 水珠按"鱼嘴在水面下半米以内全算、两米以下才没有"（到 2026-11-25）。水下的鱼头顶冒水珠，像凭空出来的。

## 9. 涟漪（`rippleField.js`、`ripples.js`、`wakeMarks.js`）

水面自己的起伏。标准是往水里扔一块石头：水面要自己起圈、扩出去、消退。外观（颜色、浪、雾、光照）不动，只给水面加一份高度和倾斜。

### 9.1 分层

| 文件 | 回答什么 |
|---|---|
| `src/shore/rippleField.js` | 水面上现在有哪些圈和尾迹段；任何一点现在高多少、斜多少。不引 Three，可以在 Node 里跑 |
| `src/shore/wakeMarks.js` | 线、鱼、饵这三样走着的东西各在水面上留什么：算多重、留几成、多久一段、在水面时高几倍。不引 Three |
| `src/shore/waterTop.js` | 一个东西在这个深度算不算在水面上（和水纹共用，第 8 节） |
| `src/shore/ripples.js` | 把这些数交给水面的着色器；同一个公式用着色器的写法再写一遍 |
| `src/shore/minamo/ocean/waterMaterial.js` | 水面。多收一个 `ripples`：顶点加它的高度，法线加它的倾斜。别的不动 |

数据只往一个方向走：有人说"这里被砸了一下"或者水纹说"该留一段了" → `rippleField` 记下来、每帧只加年纪 → `ripples` 把每一条的位置、跑了多远、多高、多宽交给着色器 → 水面的每个像素按公式算倾斜。

### 9.2 不能破的规则

**它只认哪里、多重、多沉、多深。** 砸它的是饵、是鱼还是石头，它不知道。

**一条是"过了多久"的函数，不积分。** 每帧只把每一条的年纪加上去。所以各帧率下一样，Node 里能逐点对。

**倾斜在每个像素上按公式现算，不是从一张图里采的。** 所以二十多米外和脚边一样清楚。高度只在水面网格够密的地方挪顶点；再远，几厘米的高度不到一个像素，只看得见倾斜带来的明暗。

**深浅的规则只在物料里。** 玩法只报东西多深、使了几成劲；深了变成什么样是这里的事。

**`ripples.js` 里着色器写的那个公式，和 `rippleField.js` 的 `ringAt`、`armAt` 必须是同一个。** 改一边要改另一边。

### 9.3 砸一下：一圈圈的圆

- **一砸就起。** 砸下去的那一刻，东西周围的水就站起来：最前面一圈一开始就在东西旁边（`STARTS`），二十分之一秒到一半高（`RISES`），然后往外扩。
- 最前面一圈往外跑，后面跟着两三道，越靠里越低；圈越大越矮，过几秒就没了。几处的圈互相穿过去，叠在一起。
- **多大跟着力度和重量走。** 越沉的东西圈距越宽、跑得越快、留得越久；砸得越重圈越高，也宽一点。重一百倍，圈大两倍多（`BY_WEIGHT`）。

| 谁砸的 | 圈距 | 刚砸完最高的一圈 | 看得见的圈最远到 |
|---|---|---|---|
| 饵，全力抛 | 0.40 米 | 4.0 厘米 | 2.4 米 |
| 饵，轻轻落下（力度 0.3） | 0.32 米 | 1.2 厘米 | |
| 小鱼出水 | 0.46 米 | 2.5 厘米 | 2.0 米 |
| 大鱼出水 | 0.56 米 | 3.0 厘米 | 2.8 米 |

鱼出水只算先破水的头和肩，是鱼重的一成（`catch.js` 的 `BREAKS_WITH`）。

### 9.4 走着的东西：两条斜臂的尾迹

走着的东西留的不是一串圆。它每隔零点一秒上下留下一小段，这一段只往两侧偏后送出去；一段接一段，沿路连成两条臂，波峰顺着臂排。两臂之间、它自己走过的那条线上是平的。

- **张多开看它多快。** 波跑多快除以东西走多快，是半张角的正弦；最宽不过 19.47 度（开尔文角，`KELVIN`）。慢的东西拖宽的 V，快的拖窄的。量到鱼每秒 4 米时约 13 度，每秒 1.5 米时约 19 度。依据见 [SEA-FEEDBACK-RESEARCH.md](./SEA-FEEDBACK-RESEARCH.md) 的"尾迹"几行。
- **按时间留，不按路程。** 一段要和前后两段叠上才连得成臂；慢的东西送出去得也慢，得留得更密。每秒留几段是定的，跟帧率无关。
- 尾迹比砸出来的圈消得快（`WAKE_LASTS`）。

三样东西各留什么（`wakeMarks.js`）：

| 谁 | 算多重 | 留几成 | 多久一段 | 在水面时高几倍 | 量到 |
|---|---|---|---|---|---|
| 线入水的那一点 | 0.3 克 | 0.35 | 0.1 秒（原来 0.07：它淡，算力留给鱼的） | 1 | 每秒 2 米时两臂高约 0.25 厘米、圈距 0.15 米上下 |
| 钩住的鱼 | 它自己的重量，0.66 到 2.16 公斤（玩法报） | 1.3 | 0.12 秒 | 2 | 在水面、每秒 4 米时两臂高约 8.5 厘米、圈距 1 米 |
| 水下拖着的饵 | 10 克 | 1.2 | 0.1 秒 | 1 | 每秒 1 米、0.4 米深时每段 0.8 厘米、圈距 0.85 米 |

"在水面时高几倍"只加高、不加宽：鱼背切开水面，搅得比在下面厉害得多。

### 9.5 深浅

**水面上的东西让水面猛地动，水下的让它缓缓地动，出了水的不动它。**

- **水下**：东西上面隔着一层水，尖的起伏传不上来。每深 0.6 米高度剩三分之一上下（`FADES`），每深 0.25 米圈距宽一倍（`SOFTENS`）。半米以内是一道慢的、低的缓涌。
- **沉得很深的一下**（咬口）：深过 0.9 米的都按 0.9 米算（`DEEP_AS`），水面起一圈很淡很宽的圆，免得手上顿了一下、眼前什么都没有。照实是没有的。只对"一下"这样；深处走着的东西在水面上不留尾迹。
- **贴着水面**：最强。鱼的尾迹在这里加高一倍，水珠也只在这里有。
- **高出水面**：高出 5 厘米就什么都不留（`waterTop.js`）。

量到的：

| 谁 | 在水下时 | 在水面时 |
|---|---|---|
| 钩住的鱼，冲 | 鱼在 0.35 到 0.5 米：每段高 4.0 到 4.2 厘米、圈距约 2 米，不甩水珠 | 每段高 13 到 14 厘米、圈距 1.0 米，甩水珠 |
| 钩住的鱼，歇着被拖 | 每段 1.9 到 2.0 厘米、圈距 1.4 到 1.5 米 | 每段 5.5 到 6.1 厘米、圈距 0.75 米 |
| 中咬，一公斤的鱼 | 饵在 0.4 米：2.7 厘米、圈距 2 米；0.9 米及更深（到沉底 2.4 米）：1.2 厘米、圈距 3.5 米 | — |

"每段高"是一段尾迹刚留下时的标称高度；连成臂以后实际立起来的大约是它的四成到六成。

### 9.6 谁碰水

| 谁 | 怎么来的 | 口子 |
|---|---|---|
| 饵落水 | 玩法报一下，同时起水花 | `surface.burst(x, z, 力度, 重量)` |
| 鱼出水 | 玩法报一下，同时起出水的水花 | `surface.breach(x, z, 力度, 重量)` |
| 遛鱼时鱼背露出水面、落回水里 | 玩法读鱼背多深，这两下各报一次，落回去的那一下落得越快越重（`surfacing.js`） | `surface.thrash(x, z, 力度, 重量)` |
| 水花里落回去的水珠 | 水花报一下，`startShore` 接到涟漪上 | `ripples.poke` |
| 咬口的每一下顿 | 玩法报一下，只起圈不起水花。力度是手上那一下的轻重，重量是咬的那条鱼，深度是饵的深度 | `surface.stir(x, z, 力度, 重量, 多深)` |
| 线入水的那一点 | 没有人触发，水纹读它多快 | `marksOf(LINE_WAKE, ripples)` |
| 钩住的鱼 | 没有人触发。玩法本来就带着鱼的水纹 | `marksOf(FISH_WAKE, ripples)` |
| 水下拖着的饵 | 没有人触发 | `marksOf(LURE_WAKE, ripples)` |

`surface` 是 `startShore` 交给玩法的：`burst`、`breach`、`thrash` 同时叫水花和涟漪，`stir` 只叫涟漪。

钩住的鱼平常待在水下，头顶只是缓涌；玩家抬竿把它带到水面，它才甩水珠、拖尖的尾迹；它跟着竿的回弹上下，背露出水面的那一下水面没有动静。规则在 [PLAY.md](./PLAY.md) 第 8 节。

### 9.7 比照实大多少

10 克的饵真的砸出来的是几毫米高、几厘米一圈、一两米就没的细纹。饵现在的圈约是它的十五倍高、十倍宽，传得约三倍远。镜头离水面 1.7 米，全抛 22 米外的水面被压扁到十三比一，照实的圈不到一个像素。水下的东西照实在水面上更淡（见 [SEA-FEEDBACK-RESEARCH.md](./SEA-FEEDBACK-RESEARCH.md)），现在的缓涌是为了读得出水下有东西在动。

### 9.8 常量

| 常量（`rippleField.js`） | 值 | 管什么 |
|---|---|---|
| `WEIGHT` | 0.01 公斤 | 下面这些数是给多沉的东西定的：就是饵 |
| `APART`、`SOFT_APART` | 0.4 米、0.7 | 全力时一圈到下一圈多远；最轻的一下是它的几成。整体嫌大嫌小先调 `APART` |
| `BY_WEIGHT` | 1/6 次方 | 重量变了圈跟着变多少 |
| `HEIGHT` | 0.04 米 | 全力、刚砸完时最高的一圈多高。只嫌太显眼或太淡调它 |
| `SPEED` | 0.78 米/秒 | 最前面那一圈往外跑多快。圈距宽的按平方根更快 |
| `STARTS`、`RISES` | 0.6 圈、0.05 秒 | 砸下去那一刻最前面一圈已经在多远；圈多快站起来 |
| `BEHIND` | 0.9 | 最高的一圈在最前面往里第几圈 |
| `WIDENS`、`LASTS` | 1.25 圈、1.9 秒 | 圈大到几个圈距矮三成；多久矮到三分之一（圈距宽的更久） |
| `MIDDLE` | 0.19 圈 | 正中间多大一块压平（东西本身在那里） |
| `KELVIN` | 1/3 | 尾迹最宽张多开：19.47 度的正弦 |
| `ARM_WIDE` | 0.34 | 一段尾迹往两侧送出去多宽的一片。调大更像整圆，调小臂会断成一粒一粒 |
| `WAKE_LASTS` | 0.45 | 尾迹的寿命是砸出来的圈的几成 |
| `DEEP_AS` | 0.9 米 | 砸的那一下深过这个，按这个深度算 |
| `FADES`、`SOFTENS` | 0.6 米、0.25 米 | 水下的东西每深多少高度剩三分之一；每深多少圈距宽一倍。嫌水下的太淡调大 `FADES`，嫌不够柔调小 `SOFTENS` |
| `GONE_UNDER` | 1.2 毫米 | 最高的一圈低过这个就忘掉 |
| `MOST` | 40 | 同时最多几条。再多，最矮的让位 |

三样东西的数在 `wakeMarks.js`，见 9.4 的表。

口子：`createRipples()` 返回 `poke(x, z, 力度, 重量, 多深)`（砸一下，整圆）、`trail({ x, z, strength, weight, dirX, dirZ, speed, depth, taller })`（走着的东西留一段）、`update(dt)`（每帧一次，画水面之前）、`field`（`heightAt(x, z)`、`slopeAt(x, z)`，给检查和以后浮在水上的东西读）、`at`（给水面材质）。

### 9.10 试过不要的

| 试过的 | 为什么不要 |
|---|---|
| 会传开的高度贴图（[WATER-RESEARCH.md](./WATER-RESEARCH.md) 第 2 节原来的方案） | 贴图有格子，全抛距离上一圈只有一两个像素宽；每帧迭代的结果跟帧率走；手机上多一遍计算。代价是现在的圈不会被石头挡回来 |
| 圈不分轻重，圈距 0.8 米 | 截图里清楚，手机上偏大 |
| 圈从正中间的零开始长 | 砸完 0.2 到 0.3 秒才到一半高，鱼都出水了水才动 |
| 走着的东西每走一段砸一个整圆 | 一个个圆各管各的，不像东西游过去 |
| 尾迹按路程留 | 慢鱼的尾迹散成一粒一粒 |
| 水下一米以内全按水面算 | 水下的东西头顶出尖圈，像凭空出来的 |
| 水下 0.2 米以下一点没有 | 鱼就在一掌深的地方，水面却是死的 |
| `FADES` 0.45 米；0.7 米 | 前一个拖着的东西太淡；后一个沉到底的咬口会在水面露出来 |
| 鱼出水按整条鱼的重量 | 大鱼出水的圈跑到 5 米外，是落水的饵的两倍 |
| 钩住的鱼起尾迹都按 1.2 公斤算 | 它们有自己的重量 |
| 沉到底的咬口水面完全不动 | 照实，但手上顿了一下、眼前什么都没有 |
| 水花自己画两道圈 | 水面现在自己起圈，两样叠着 |
