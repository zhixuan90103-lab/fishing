# 玩法层

状态：一竿能从头走到尾：空杆、甩出、飞行、落水、长按收线，鱼从鱼群里游来咬上，冲的时候把线带出去，耗到没力以后收到身边，咬着饵甩着被提出水面，抄网从旁边伸到它下面，它脱钩落进网里接着甩，网带着它出了画面这一竿结束。每条鱼都直接咬死，这是替身，见第 10 节。咬口的种类、抬杆、线断、线放尽还没做。真机上的手感没有确认。  
规则以 [FISHING-REQUIREMENTS.md](./FISHING-REQUIREMENTS.md) 为准，这里只写规则怎么落到代码上，以及需求里没定、先填上的数字。

这是工程里唯一写钓鱼规则的地方。物料（竿、线、渔轮、饵、鱼群、手机瞄准）不知道有这一层。

## 1. 分层

| 文件 | 回答什么 |
|---|---|
| `src/play/swing.js` | 手机甩得多用力，这么用力能抛多远 |
| `src/play/retrieve.js` | 空竿按住时线收多快 |
| `src/play/lineOut.js` | 竿尖外现在放出多长的线，线上带着多少余线 |
| `src/play/visit.js` | 一条鱼怎么游到饵跟前，嘴离饵多近算碰到钩 |
| `src/play/fight.js` | 钩住的鱼这一刻用多大力，还剩多少气力，这个力把它带向哪 |
| `src/play/haul.js` | 挂着鱼按住时线收多快，张力到多大线就收不动、开始往外出，出多少 |
| `src/play/scoop.js` | 抄网的圈随时间走到哪，鱼什么时候脱钩、怎么落进网，网怎么被砸得一沉。见 [NET.md](./NET.md) |
| `src/play/fishing.js` | 这一竿走到哪一段，每一段里手指按着是什么意思；哪条鱼来、什么时候算钩住、什么时候算到了身边；把上面几层和饵的运动接到物料的口子上 |

前七个只算数，互相不知道对方，也不知道物料。`fishing.js` 是唯一知道物料的：它每帧问这几层和 [LURE.md](./LURE.md) 的 `lureMove` 要数，再告诉线、饵、渔轮、鱼群和镜头。数据只往一个方向走：输入 → 各层算数 → `fishing` → 物料。

这些文件都不引 Three。只算数的可以单独在 Node 里跑，`fishing.js` 可以用假的竿和线、真的鱼群（`flock.js`）在 Node 里把一整竿走一遍。

`src/shore/startShore.js` 只创建它，并在每帧鱼群动过以后调用 `fishing.update`、在 `line.update` 之后调用 `fishing.follow`。

## 2. 不能破的规则

**规则只写在这一层。** 物料只报数。线多硬、饵在哪是物料给的；甩得够不够算一次抛投、线收到多短算收完，是这里判的。

**只通过口子动物料。** 想让竿受力，改线长或线的远端，不往竿尖加力。镜头不直接动，只报出要看的点（`watch`）。

**饵不瞬移，线长不跳。** 换段的时候位置和线长接得上。线上的余线是渐渐收掉的，不在某一帧归零。

**力度在手上量，不在竿尖量。** 竿身软，竿尖跟不上手，见第 4 节。

**鱼不被线拖着走。** 玩法只告诉鱼线被拉长了多少，鱼自己游过去。不改鱼的位置，见 [FISH-SCHOOL.md](./FISH-SCHOOL.md) 第 2 节。

## 3. 一竿的五段（`fishing.js`）

| 段 | 画面 | 手指按下 | 手指松开 | 怎么出去 |
|---|---|---|---|---|
| `ready` 空杆 | 线收到头，饵贴在竿尖，跟着竿尖走，不晃 | 镜头定住，开始量这一甩。线不出 | 正在向前甩：饵飞出去。否则什么都不发生 | 松手时手机向前倾得够快 → `flight` |
| `flight` 飞行 | 饵在空中，线跟着放 | 出线停下，饵在已经飞出的距离落下 | 不恢复出线 | 饵碰到水面 → `water` |
| `water` 水里 | 饵在水下。线在落水后约半秒内自己变直。过一会儿一条鱼离开鱼群游过来 | 收线。但落水时就按着的那一下不算，要先松开 | 不收线，饵停在原地 | 线收到头 → `ready`。鱼嘴碰到饵 → `fight` |
| `fight` 挂着鱼 | 饵在鱼嘴里，线连到鱼嘴。鱼自己冲一阵、歇一阵，竿被拉弯。冲的力超过出线点时线被它带出去 | 顶着鱼收线。线在出的时候收不动 | 不收线。线照样出 | 鱼没力再出线、又到了身边 → `landed` |
| `landed` 提鱼 | 鱼咬着饵挂在线上，身子顺着线垂下来，还在甩。它的重量压在竿尖上 | 把它提出水面，提到竿尖下面 | 停在原处 | 提到头以后吊一小会儿，抄网伸到它下面，它脱钩落进网里，网带着它出了画面 → `water`，剩下的线自己收完 → `ready` |

每一段是一个函数，进入一段要做的事各有一个 `toReady` / `toFlight` / `toWater` / `toFight` / `toLanded`，网把鱼带走是 `toNetted`。每段自己的记号写在文件顶部，按段分组。

- **空杆时饵是固定在竿尖的，不是挂着的。** 甩竿蓄力时竿尖走得很快，挂着的饵会被甩得乱荡，既挡视线又让出手的位置不定。这一段用 `lureMove.hold`，线用 `line.stow`。
- **只算按住以后的甩。** 手指按下时把力度的读数清零。
- **饵一离开竿尖，镜头就转向落点，转到了就停在那里。** 甩竿时手常常抬得很高，镜头如果停在按下时的朝向，看到的是天。它看的是水面上的落点，不是饵：出手时落点就已经算出来了，镜头一次转过去，不跟着饵先仰后俯，收线时也不跟着饵往回走。出线被按停时饵落得更近，落水那一下落点换成真正的位置，镜头再低一点。这段时间手机只动竿，竿仍然指着手机指的方向。`fishing.watch` 报出这个点，怎么转、转多快、上下限在 [PHONE-LOOK.md](./PHONE-LOOK.md) 第 4 节。饵被提出水面以后 `watch` 是空的，镜头回到手机。
- **饵落水时起一次水花**（`splash.burst`）。力度按饵碰到水面时的速度算，到 `SPLASH_FULL` 是最大；出线被按停、饵只是掉下去时水花小一些。
- **回到 `ready` 以后要先松一次手**，下一次按下才算新的一竿。收线一直按到底不会直接变成下一次甩竿。
- **饵靠近到竿尖正下方 `LIFT_WITHIN` 以内时被线提出水面**，之后是挂在线上的重物，会荡；继续按住就一直收到竿尖，收到头就又固定住了。
- **线只在饵在水里时拉竿**（`line.setTied(true)`）。饵在竿尖、在空中、被提起来以后都不拉。
- **收了多少线就让渔轮转多少**（`rod.reel.wind`）。抛出去时线是自己放的，渔轮不转。

鱼这一半：

- **来的是离饵最近的那条。** 落水后过 `COME_AFTER` 里随机的一段时间，从鱼群里取出它（`school.take`），它从自己原来的地方游过来，全程看得见。碰钩之前线上没有它的重量。
- **鱼还没到，饵就被提出水面了，这条鱼放回去**（`school.giveBack`），这一竿照常收完。
- **嘴碰到饵就是钩住。** 现在每一口都是咬死，不用抬杆，这是替身，见第 10 节。钩住的那一下震一次（`haptics.impact('heavy')`），鱼立刻开始第一冲，空竿收线的速度停掉；手指这时如果按着，就是顶着鱼在收。
- **钩住以后饵在鱼嘴里。** 每帧把饵和线的远端放到鱼嘴这一帧的位置，不再调 `lureMove` 的几种动法。鱼群因此在 `fishing.update` 之前更新。
- **镜头跟着鱼，但跟得很慢。** `watch` 的那个点按 `WATCH_FOLLOW` 追鱼嘴在水面上的投影，鱼来回游的时候画面不跟着甩。
- **线被带出去时不管手指。** 张力过了出线点，渔轮就让出线，让出的正好是把张力带回出线点的那么多（`haul.slip`）。按着也出，松开也出。线最多放到 `SPOOL`，到了就不再让。线放尽以后怎么办还没做。
- **渔轮在手里"咔咔"响。** 线每被带出去 `CLICK_OUT` 震一下，脆而重；顶着鱼每收回 `CLICK_IN` 震一下，钝一些，线越紧越重（`haptics.playTransient`）。出线越快咔得越密，所以冲得多猛手上直接读得出来。把竿往鱼的反方向带，线被拉紧，张力上去，过了出线点同样出线、同样咔。
- **鱼的力低于出线点、离竿尖正下方又不到 `LAND_WITHIN`，才算到了身边。** 力还高的时候到不了：它一冲线就出去。
- **到了身边，鱼就是挂在饵上的重物。** 饵改用 `lureMove.hang`，鱼用 `school.hang` 挂在饵上：嘴在饵的位置，身子顺着线垂下来。按住把它提出水面。线原来被它拉长的那一点在零点几秒里退掉（`SLACKEN_RATE`），竿是慢慢松直的，不是弹直。
- **鱼的重量压在竿尖上，不走线。** 用的是竿留的 `rod.setTipLoad`。鱼还在水里时只算 `SUNK_SHARE`，饵从 `DRY_FROM` 升到 `DRY_BY` 的过程里加到全重，所以竿是随着鱼出水一点点压下去的。重量按 `LOAD_STEP` 一小步一小步交给竿。试过让线带着重量去拉竿：竿很轻很软，线又短又硬，两边隔着一帧互相等，张力在 0 和尖峰之间跳，60 帧和 20 帧的结果也不一样。
- **出水的那一下它猛甩。** 饵升到出水一半时，鱼甩的力度一下子加上去（`KICK_SURFACE`），那里溅一次水花，震一下，然后按 `KICK_FADE` 退回平常。怎么甩是鱼的事，玩法只给 `school.hang` 一个"现在甩多用力"的数。
- **提到线只剩 `SHOW_LENGTH`，吊 `SHOW_FOR`，然后叫抄网。** 网从镜头的左边、略靠近钓手的一侧进来（拿竿的是右手），停在鱼尾下面。路径在 `scoop.js`，模型在 `net.js`，见 [NET.md](./NET.md)。
- **鱼脱钩，落进网里。** 饵留在线上，是光的了；鱼的重量从竿尖上撤掉，竿慢慢直回来。鱼尾巴朝下落进网兜，落网那一下震一次，甩得最猛（`KICK_NET`）；网被砸得一沉再弹回，网兜坠长、左右晃。之后它在网里一阵一阵地甩：每隔 `FIT_EVERY` 再来一下（`FIT_KICK`），每一下轻震一次。网把它端起来一点。
- **网出了画面，这一竿就结束了。** 鱼这时看不见，交还给鱼群（`school.keep`），它从画面外游回来。线不用按、自己收完。钓到几条在到身边的那一下加一。

| 常量 | 值 | 管什么 |
|---|---|---|
| `LIFT_WITHIN` | 1.6 米 | 饵离竿尖正下方这么近时被提出水面 |
| `SPLASH_FULL` | 14 米/秒 | 饵以这个速度碰到水面时水花最大 |
| `DESK_FULL_HOLD` | 1 秒 | 只用于桌面：没有传感器时，按住这么久算一次全力的甩 |
| `COME_AFTER` | 1.5 到 4 秒 | 饵落水后多久有鱼动身。每一竿取一次 |
| `LAND_WITHIN` | 2.2 米 | 钩住的鱼离竿尖正下方这么近算到了身边 |
| `WATCH_FOLLOW` | 1.2 /秒 | 挂着鱼时镜头看的点追鱼追多快。调大画面跟得紧，也更晃 |
| `SPOOL` | 70 米 | 鱼最多能把线带出去多长 |
| `BOIL_SPLASH`、`BOIL_ABOVE`、`BOIL_WITHIN` | 0.7、0.2、−1 米 | 鱼起冲时翻的水花：气力满时多大；气力低于多少、鱼比多深更深就不翻 |
| `CLICK_OUT`、`CLICK_IN` | 0.09、0.3 米 | 线每出去、每收回这么多震一下。调小咔得更密 |
| `SHOW_LENGTH`、`SHOW_FOR` | 0.6 米、0.6 秒 | 鱼提到线剩多长为止，吊多久以后叫网 |
| `KICK_SURFACE`、`KICK_NET`、`KICK_FADE` | 1.3、2.2、1.6 /秒 | 出水和落网时比平常多甩多少，退得多快 |
| `FIT_EVERY`、`FIT_KICK` | 0.35 到 0.8 秒、1.4 | 在网里隔多久再甩一阵，每阵多用力 |
| `BREAK_SPLASH` | 0.45 | 鱼出水那次水花的力度，0 到 1 |
| `NET_NEARER` | 0.45 | 网来的方向：每往左一米，同时往钓手这边靠多少 |
| `FISH_LOAD` | 0.05 千克 | 出了水的鱼在竿尖上算多重。不是真实的重量：竿身很轻，这么多已经压得很深 |
| `SUNK_SHARE`、`DRY_FROM`、`DRY_BY` | 0.25、−0.3、0.25 米 | 还在水里时算几成重；饵升到哪开始加、到哪加满 |
| `LOAD_RATE`、`LOAD_STEP` | 6 /秒、0.001 千克 | 竿尖上的重量跟得多快，每次交给竿多大一步 |
| `LIFT_AS` | 3.2 牛 | 提鱼时线速按顶着这么大的张力算，约 0.6 米/秒 |
| `SLACKEN_RATE` | 4 /秒 | 到身边以后，线上原来的拉长退掉多快 |

## 4. 甩（`swing.js`）

力度是手机向前倾得多快，也就是瞄准的俯仰往下掉的角速度，单位度/秒。读法是让一个值追着俯仰，落后多少就是角速度，不对两帧做差。

**在手上量，不在竿尖量。** 竿身很软，快速一甩时竿尖先落在后面、再弹过去，它的速度反映的是竿身而不是这一甩。用真实的竿模型算过：手以 220°/秒甩，竿尖向前的速度只有约 1.2 米/秒，而且峰值出现在手停下以后。最初的版本量竿尖，结果怎么甩都出不了线。

松手稍晚也算：最近的最大值按 `BEST_FADE` 慢慢退。

方向不由甩决定。按下时镜头已经定住，饵沿镜头的朝向飞出去。

| 常量 | 值 | 管什么 |
|---|---|---|
| `TRAIL_RATE` | 18 /秒 | 追俯仰的值跟得多紧。读到的角速度大约滞后 1/18 秒。调小更稳也更迟，很短促的一甩会读得偏小 |
| `BEST_FADE` | 4 /秒 | 最大值退得多快。调小，甩完以后晚一点松手也还算数 |
| `SWING_MIN` | 120°/秒 | 低于它松手不算抛投 |
| `SWING_FULL` | 750°/秒 | 到这个角速度抛到最远 |
| `REACH_MIN`、`REACH_MAX` | 4、28 米 | 最近和最远的落点，从竿尖正下方算 |
| `REACH_CURVE` | 1.6 | 两者之间距离怎么涨。1 是和角速度成正比。大于 1，轻甩和中等的甩都落得近，远投留给用力的那几下 |

**力度要能从落点上看出来。** 松手时读到的角速度和落点：

| 角速度 | 150°/秒 | 200 | 300 | 400 | 500 | 600 | 750 以上 |
|---|---|---|---|---|---|---|---|
| 落点 | 4.2 米 | 4.9 | 7.2 | 10.6 | 14.7 | 19.5 | 28 |

第一版是 90 到 420°/秒、中间走 S 形，手随便一甩就过了三四百，落点全挤在二十米以外，分不出轻重。现在范围拉宽到 750，曲线前缓后陡。

松手晚了读数会退：甩完 0.15 秒才松手剩一半左右，停下 0.4 秒以后基本不算抛投。

## 5. 收（`retrieve.js`）

每一次按下都从头开始：缓起到慢速，保持，再升到匀速，然后一直匀速。不接着上一次的速度。松手时线不是立刻停死，原来的速度很快滑掉；这时再按下，新的一次从零起，和还没滑完的那一点叠在一起，所以线速不会跳。

收了多少线是速度的精确积分，不随帧率变。

| 常量 | 值 | 管什么 |
|---|---|---|
| `SLOW_SPEED` | 0.3 米/秒 | 每次按下开头的慢速 |
| `EASE_IN` | 0.15 秒 | 从 0 到慢速用多久 |
| `SLOW_FOR` | 0.6 秒 | 按下以后多久开始加速 |
| `RISE` | 0.9 秒 | 从慢速升到匀速用多久 |
| `STEADY_SPEED` | 1.2 米/秒 | 匀速。调大饵回来得快，竿上也更重 |
| `COAST_RATE` | 9 /秒 | 松手后线速滑掉的快慢 |

按住 3 秒收 2.63 米。25 米的线收完约 23 秒。

## 6. 线放出多长（`lineOut.js`）

这一层只管一个数：竿尖外的线长。它不知道线怎么画、饵在哪，只收 `gap`（竿尖到饵的直线距离）和这一帧收了多少线。

| 调用 | 什么时候 | 线长变成 |
|---|---|---|
| `stow()` | 回到空杆 | `STOW_LENGTH` |
| `fly(gap)` | 飞行中每帧 | 两端的距离再多出 `FLIGHT_SPARE`，线在空中有一点弧 |
| `land(gap)` | 落水那一帧 | 不变。多出来的那段记成余线 |
| `wind(dt, taken, gap)` | 水里每帧 | 有余线时：余线按 `SETTLE_RATE` 自己退，收的线也先扣在它上面，线长是距离加余线。没有余线了：线长减去收的线 |
| `ease(gap)` | 饵被提出水面那一帧 | 如果线正被拉长，放回到两端的距离，饵不会被猛地拽一下 |

`wind` 返回这一帧收的线里有多少真正拉到了饵：余线还在时是 0，线直了以后是全部。`fishing.js` 把它交给 `lureMove.tow`。

**线不在落水那一帧跳直。** 25 米的抛投落水时线上约有 0.9 米余线，画出来是一段弧。它在 0.25 秒后剩约四分之一，0.5 秒后剩不到一成。这半秒里按住收线，先收掉的是剩下的余线。这不是需求里排除的"先收一截虚线"：不按它也自己变直，玩家不用为它做任何事。

| 常量 | 值 | 管什么 |
|---|---|---|
| `STOW_LENGTH` | 0.025 米 | 收好时竿尖外留多长的线：饵的鼻尖正好在竿尖的导环下面。线回到这么长，这一竿结束 |
| `FLIGHT_SPARE` | 0.04 | 飞行时线比两端的距离多放出的比例 |
| `SETTLE_RATE` | 5 /秒 | 落水后余线退掉的快慢。调小线直得更慢 |
| `SETTLE_DONE` | 0.002 米 | 余线小于它就算直了 |

## 7. 鱼游过来（`visit.js`）

只写鱼的目标，鱼由 `swim.js` 游过去。朝向指着饵，深度是饵的深度，速度是饵自己的速度再加一截：远处加 `CLOSE_FAR`，到了饵跟前降到 `CLOSE_NEAR`。饵正在被收回来时鱼仍然追得上。

鱼不能倒着游，所以有两处要管：

- **没对准时先慢下来转。** 鱼头和饵的方向差得越多游得越慢，最慢是 `OFF_LINE` 这个比例。
- **游过头了就继续往前，离开一段再掉头。** 饵在嘴后面、离鱼身又不到 `PAST_UNTIL` 时，它保持原来的朝向游出去。马上掉头的话，它会把饵压在肚子下面一直打转，嘴永远碰不到。

嘴离饵不到 `TOUCH` 就算碰到钩。

| 常量 | 值 | 管什么 |
|---|---|---|
| `CLOSE_FAR`、`CLOSE_NEAR` | 1.3、0.3 米/秒 | 远处和饵跟前，鱼比饵快多少 |
| `NEAR` | 1.6 米 | 离饵这么近开始从前一个速度降到后一个 |
| `OFF_LINE` | 0.15 | 没对准饵时速度降到几成 |
| `PAST_SPEED`、`PAST_UNTIL` | 0.6 米/秒、0.8 米 | 游过头以后继续往前的速度（在饵的速度之上），和游出多远才掉头 |
| `TOUCH` | 0.14 米 | 嘴离饵这么近算碰到钩 |
| `SHALLOWEST` | −0.22 米 | 鱼为了饵最浅游到哪 |
| `TURN`、`ACCEL`、`SLOW`、`RISE` | 4.2、2.6、3、1.8 /秒 | 这一路上转向、提速、减速、换深度各多快 |

在 Node 里从鱼群旁边 5 到 27 米处放一只饵，60 个随机种子、20 到 120 帧：全部碰到钩。饵停着时从动身到碰钩平均约 4.5 秒，最慢约 10 秒；饵在收时更快。

## 8. 钩住的鱼（`fight.js`）和顶着鱼收线（`haul.js`）

### 鱼的力和气力

鱼冲一阵、歇一阵，各自的时长每次重新取。歇的时候它的力是 `REST_FORCE`，不是零，所以线一直是绷着的，竿不弹直。力上得快、退得慢：竿是立刻弯下去的，再慢慢松成浅弯。

**冲和歇要在鱼身上就分得出来，不靠震动。** 冲是逃命：力一下子上来，鱼猛地加速，一边往外带线一边左右急窜、往下扎；气力还足、又在水面附近时，它起冲的地方翻一次水花。歇是停滞：它几乎不动，浮在靠近水面的地方挂在线上，只有线领着它才往回走。歇有时被掐得很短，眼看它不动了又突然窜出去。震动是在这个差别上再加一层。

冲的力看气力。气力从 1 到 0：满的时候冲的力是 `RUN_FRESH`，高于出线点，这一冲线就被带出去；耗尽的时候是 `RUN_SPENT`，低于出线点，线出不去了，这时才收得到身边。

| 这时候 | 气力 |
|---|---|
| 正在冲 | 每秒掉 `TIRE_RUNNING` |
| 没在冲，线正被收回来 | 每收一米掉 `TIRE_PER_METRE` |
| 没在冲，也没在收 | 每秒回 `RECOVER` |

和气力比的不是出线点。和出线点比的是这一冲的力。

### 力怎么变成游动

**鱼不被线拖。** 玩法告诉它线被拉长了多少，它自己游到"线的拉力正好等于它的力"的那个距离上：

- 比那个距离远，它掉头往回游；比它近，它往外游；正好在那里，它横着游，绕着竿尖走弧线。
- 按住收线时，那个距离跟着线一起变近，它就头朝着岸被领回来。领它回来要多花的张力是 `BODY_DRAG` × 线速。
- 它的力超过出线点时没有这样一个距离：线拉不住它。它往外游的速度是（力 − 出线点）÷ `BODY_DRAG`，线就按这个速度出去。
- 横着游到离抛投方向 `KEEP_WITHIN` 以外就折回来，所以它一直在钓手前面的水里。

它追的是一个位置，不是按"力差多少"加速。线越短越硬，按力来算的话鱼会冲过头再被拽回来，线越短抖得越厉害；按位置去追，线多硬收敛都一样。

**把竿往反方向带是有阻力的。** 竿尖走远，线被拉长，鱼要过 `SETTLE_IN` 才让过来，这段时间张力是高的：竿弯得更深，过了出线点就出线，手里咔咔响。

鱼不能原地掉头。要转的角度超过一个直角时，它慢到 `TURNING` 这个比例，并且往竿这一侧绕（`TURN_INSIDE`）。从外侧绕等于猛拽一下线。

靠近岸边时它不往下扎：线几乎是竖着连到它的，往下扎等于直着拉一根又短又硬的线。

| 常量 | 值 | 管什么 |
|---|---|---|
| `RUN_FRESH`、`RUN_SPENT` | 9.5、2.4 牛 | 气力满和耗尽时冲的力。前者比出线点高多少，定线出得多快 |
| `RUN_FADE` | 0.6 | 冲的力按气力的这个次方掉。小于 1：前几冲都还很猛，快没力时才一下子掉下来 |
| `REST_FORCE` | 1 牛 | 歇的时候的力，定歇的时候线绷多紧 |
| `TIRE_RUNNING`、`TIRE_PER_METRE`、`RECOVER` | 0.12 /秒、0.03 /米、0.03 /秒 | 气力怎么掉、怎么回。第一个调小，要冲更多次才累 |
| `FORCE_ON`、`FORCE_OFF` | 14、3 /秒 | 力上来和退掉的快慢。上来是猛地一拽 |
| `RUN_FOR`、`RUN_SPENT_SHARE` | 1.6 到 3.2 秒、0.55 | 气力满时一冲多久；耗尽时只有它的这么多 |
| `REST_FOR` | 1.8 到 4.5 秒 | 一歇多久 |
| `REST_SHORT`、`SHORT_CHANCE` | 0.35 到 0.8 秒、0.25 | 有这么大的机会，这一歇被掐短成这么久，鱼马上又冲 |
| `DART_EVERY` | 0.4 到 0.9 秒 | 带着线冲的时候隔多久换一边窜。线被拉住时不窜：那时换边等于原地掉头，是累了的样子 |
| `BODY_DRAG` | 1.5 牛/(米/秒) | 在水里拖动这条鱼要多大的力。调大，线出得慢，收线和带竿时竿上更重 |
| `SETTLE_IN` | 0.4 秒 | 鱼多快到达线拉住它的那个距离。调大，带竿时阻力留得更久；调小跟线跟得紧，低帧率下过冲更多 |
| `SLACK_SPEED` | 0.3 米/秒 | 线松着时它最多比"力带得动的速度"快多少 |
| `LED_MAX` | 1.6 米/秒 | 线最快能把它领回来多快 |
| `ACROSS_RUN`、`ACROSS_REST` | 1.2、0.07 米/秒 | 冲和歇的时候横着游多快。歇的时候几乎不动 |
| `TURNING`、`TURN_INSIDE` | 0.2、0.3 米/秒 | 掉头时速度降到几成，往竿这一侧偏多少 |
| `KEEP_WITHIN` | 35° | 从竿尖看，鱼离抛投方向最多偏多少 |
| `RUN_DEPTH`、`REST_DEPTH`、`SHALLOWEST` | −1.7、−0.5、−0.25 米 | 冲和歇的时候游多深，最浅到哪 |
| `DIVE_NEAR`、`DIVE_FAR` | 3、9 米 | 离竿尖正下方比后者远才完全扎下去，比前者近完全不扎 |
| `TURN_RUN`、`TURN_REST` | 7、3.5 /秒 | 冲和歇的时候转向多快 |
| `ACCEL_RUN`、`ACCEL_REST` | 14、5 /秒 | 冲和歇的时候提速多快 |
| `SLOW` | 8 /秒 | 被线刹住多快 |
| `RISE_RUN`、`RISE_REST` | 2.2、0.9 /秒 | 往下扎和浮回来各多快 |

### 顶着鱼收线，和出线

不是空竿的先慢后匀。按住以后线速按 `TAKE_UP` 升到一个值：`HAUL_SPEED` ×（1 − 张力 ÷ `RUN_OUT_AT`）。张力越接近出线点收得越慢，到了出线点就收不动。松手按 `LET_GO` 很快退掉。张力用的是线报的 `line.tension`。

过了出线点线往外出。`slip` 给的是一个长度，不是速度：线被拉长的量里超出"出线点 ÷ 线的软硬"的那一截，全让出去。所以结果不随帧率变，张力也停在出线点上。

| 常量 | 值 | 管什么 |
|---|---|---|
| `HAUL_SPEED` | 2 米/秒 | 张力为零时的线速。歇着的鱼实际收到约 0.9 米/秒 |
| `RUN_OUT_AT` | 4.5 牛 | 出线点。到这个张力线收不动，再高线就出去 |
| `TAKE_UP`、`LET_GO` | 4、9 /秒 | 按下后线速升得多快，松手后退得多快 |

### 量出来的数

用真的鱼群、真的竿身模型（`rodFlex.js`，握把不动、竿抬起 20°）在 Node 里跑，抛 6 到 27 米，20 帧和 60 帧各五竿：

- **出线**：最快 3.3 到 4.5 米/秒。一条鱼前后一共带出去 10 到 12 米，分四五冲。张力停在 4.5 牛，最高 4.6。
- **多久**：一直按着，从钩住到身边 28 到 57 秒，抛得越远越久。只在歇的时候按，31 到 66 秒。完全不按，四分钟后鱼还在线上，线从 10 米放到 24 到 29 米。
- **到身边时气力都是 0。**
- **提鱼和抄网**：从到身边到网出画面 8.4 秒，其中网 3.3 秒。竿尖被鱼的重量压低约 0.5 米。到身边那一下竿尖最快 1.5 米/秒左右；整竿里竿尖最快的是钩住那一下，约 4 米/秒。
- 还在游的鱼，运动方向和鱼头的夹角始终是 0。鱼离抛投方向最多偏 37°。
- 20 帧和 60 帧下这些数相近，提鱼的高度和竿的弯度一样。鱼的游动本身是按帧逼近的，所以遛鱼的时间不是一个数都不差。

竿尖的角度受线的方向限制：线在正前方、鱼又远时，竿尖最多转到和线同向，约 25°。把竿抬起来或带向旁边，弯会更深。这是竿的规则，见 [ROD.md](./ROD.md) 第 5 节。竿的软硬没有改。

## 9. 和物料的接线

| 物料 | `fishing.js` 往里送什么 | 读什么 |
|---|---|---|
| 鱼线 | `setEnd`、`setLength`、`stow`、`setTied` | `tip`、`end`、`stiffness` |
| 饵 | `lureMove` 的 `hold` / `hang` / `launch` / `fly` / `tow` / `point`，`lure.place` | 位置、鼻尖朝向、`swum`、落水时的速度 `impact` |
| 渔轮 | `rod.reel.wind` | — |
| 镜头 | 报出 `watch`：要看的点，或者空 | — |
| 水花 | `splash.burst(x, z, 力度)`：饵落水，鱼起冲时翻水，鱼出水 | — |
| 抄网 | `net.place(x, y, z, 柄的方向, 网兜拉多长, 晃多少)`、`net.hide()` | — |
| 鱼群 | `take(fish, brain)`、`giveBack(fish)`。`brain` 是 `visit.js` 或 `fight.js` 写目标的那个函数。到身边以后 `hang(..., 甩多用力)`，网带出画面以后 `keep(fish)` | `fishes`（位置、`state`）、`mouth(fish, out)` |
| 鱼线（挂着鱼时） | `setEnd` 给鱼嘴的位置 | `tension`、`stiffness`、`tip` |
| 鱼竿 | `setTipLoad(千克)`：提出水面的鱼的重量 | — |
| 震动 | `haptics.impact('heavy')` 钩住，`haptics.playTransient` 出线和收线的咔咔，`haptics.notification('success')` 到身边，`haptics.impact('medium')` 出水和落网，网里每甩一阵一下轻的，`haptics.impact('light')` 网出画面 | — |
| 手机瞄准 | — | 瞄准的俯仰，经 `startShore` 传进来 |

`update(dt, input)` 的输入由 `startShore` 给：`finger` 手指是否按着，`sensor` 有没有在读手机的姿态，`viewYaw` 镜头朝哪，`aimPitch` 手机把竿瞄得多高（镜头的俯仰加上竿的那一份）。

**每帧调两次。** `update` 在 `applyPhone` 和 `rod.update` 之前：松手那一帧镜头就要开始转向落点，晚一步它会先朝手机指的方向追出去一截。代价是它读到的竿尖是上一帧线画出来的那个。`follow` 在 `line.update` 之后：空杆时把饵摆到这一帧的竿尖上，这样饵不会比竿慢一帧。别的段里 `follow` 什么都不做。

**鱼群在 `update` 之前更新。** 饵在鱼嘴里的时候，取的是鱼这一帧的位置。反过来，鱼的 `brain` 是在鱼群更新里被调用的，它读到的线长和竿尖是上一帧的。

**没有鱼群也能跑。** `createFishing` 不给 `school` 时没有鱼来，一竿就是原来的三段。这样前半段可以照旧单独验。

**手指从 `src/shore/finger.js` 读。** 它报两样：画面上有没有按下的指针，空格键有没有按着。取哪一个由 `startShore` 定：有手机时是前者，没有时是后者。

**桌面的替身。** 桌面拖动是转镜头，所以手指换成空格键。没有传感器竿不会动，镜头看饵照常；甩的力度用按住的时间代替：按住 `DESK_FULL_HOLD` 算全力。这只是为了在桌面上把流程走通，手感以真机为准。

**调手感的读数。** `startShore()` 返回的对象上有 `fishing`，可以读 `stage`、`lineOut`、`swing`、`lastRelease`、`watch`、`lure`，以及 `fish`（`none` / `coming` / `on` / `landed`）、`mood`（`run` 冲 / `rest` 歇）、`tension`（线的张力）、`pull`（鱼自己的力）、`running`（线正在出多快）、`stamina`（气力）、`landed`（钓到几条）。设置面板最下面"这一竿"一行把它们实时显示出来。它是给调第 4 节和第 8 节那几张表用的，不是给玩家的提示。

## 10. 需求里没定、这里先填的

这些在 [FISHING-REQUIREMENTS.md](./FISHING-REQUIREMENTS.md) 第 19 节或正文里没有数字，现在的值是真机试出来之前的起点：

- 多大的甩算抛投，抛多远（第 4 节的表）。
- 空竿收线的慢速、匀速和加速时间（第 5 节的表）。
- 线收到多短算收完：`STOW_LENGTH`。
- 饵沉多快、沉多深、被拉着时游多深：`SINK_SPEED`、`SINK_FLOOR`、`RUN_DEPTH`，在 [LURE.md](./LURE.md)。
- 饵落水后多久有鱼来：`COME_AFTER`。
- 出线点 `RUN_OUT_AT`，冲和歇的力，一冲一歇多久，气力掉多快回多快（第 8 节的表）。
- 线收到多近算身边：`LAND_WITHIN`。线有多长：`SPOOL`。
- 挂着鱼时收线多快：`HAUL_SPEED`。需求只定了越接近出线点越慢。
- 震动：需求把怎么震留到后面再定。现在先有四处，见第 9 节的表。

和需求的出入：

- 需求第 6 节写"饵一落水，线就是绷直的"，实现是落水后约半秒内自己变直。一帧之内从带弧变成直线，画面上是一次跳变。
- **替身：每条鱼都咬死。** 需求第 8 节里咬死不进普通随机，只在很久没钓上或随机奖励时出现。现在嘴碰到饵就钩住，是为了先把一竿走到头。咬口做了以后换掉，`fishing.js` 的 `toFight` 上标了 `Stand-in`。
- **只有一档鱼。** 需求分小鱼和大鱼：小鱼的冲击始终低于出线点，收到身边就离水。现在每条鱼都是气力满时高于出线点、耗尽后低于出线点的那一种，也就是需求里的大鱼。
- **鱼离水以后落进抄网带走。** 需求只写到鱼离水、这一竿结束。兜走的鱼在画面外交还给鱼群，再游回来，不然鱼群会越钓越少。
- **网走以后线是自己收完的。** 需求里收线都要按住。这里这一竿已经结束，剩下的不到一米线不再要玩家按。

## 11. 还没做

- 咬口的种类（轻咬、中咬、重咬），钩在不在嘴里，抬杆，脱口。抬杆的读法可以照 `swing.js`：量瞄准的俯仰往上走的角速度。
- 跑离、惊吓、再回来。饥饿和喜好。
- 小鱼这一档，以及鱼的大小和它的力挂钩。
- 断开点和线断：出线时还按着，力叠上去，过了断开点才可能断。线放尽以后收空线。
- 鱼出水、入水时水面的反应。水花同时只能放一次。
- 线出去的时候渔轮的线杯不转。
- 来的鱼被石头挡住时会一直绕，没有换一条。
- 入水声，出线的声音。水面上真正的涟漪，饵游动时带出的纹，鱼在水线附近的动静。
- 抛投时线挡打开，线从线杯上放出去。
- 甩的方向只取镜头的朝向，往左右甩不会抛偏。

## 12. 改的时候

- 想改一竿怎么走、手指在哪一段是什么意思：改 `fishing.js`，并先改需求文档。
- 想改抛多远、多用力才算：只改 `swing.js` 的常量。
- 想改收线的快慢：只改 `retrieve.js` 的常量。
- 想改线上的弧多大、落水后直得多快、收好时留多长：只改 `lineOut.js` 的常量。
- 想改鱼游过来的快慢、多近算碰钩：只改 `visit.js` 的常量。多久来一条、来哪条，在 `fishing.js`。
- 想改鱼冲多大力、冲多久、怎么绕：只改 `fight.js` 的常量。改完用真的鱼群和竿身在 Node 里跑几十竿，看张力的最大值有没有过出线点。
