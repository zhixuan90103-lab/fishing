# 玩法层

状态：做了一竿的前半段：空杆、甩出、飞行、落水、长按收线、收完。咬口和拔河还没做。真机上的手感没有确认。  
规则以 [FISHING-REQUIREMENTS.md](./FISHING-REQUIREMENTS.md) 为准，这里只写规则怎么落到代码上，以及需求里没定、先填上的数字。

这是工程里唯一写钓鱼规则的地方。物料（竿、线、渔轮、饵、鱼群、手机瞄准）不知道有这一层。

## 1. 分层

| 文件 | 回答什么 |
|---|---|
| `src/play/fishing.js` | 这一竿走到哪一段，每一段里手指按着是什么意思，线放出多长，线的远端在哪，镜头什么时候锁 |
| `src/play/swing.js` | 手机甩得多用力，这么用力能抛多远 |
| `src/play/retrieve.js` | 空竿按住时线收多快 |

`swing.js` 和 `retrieve.js` 只算数，不引 Three，可以在 Node 里跑。`fishing.js` 也不引 Three：它只把这两层和饵的运动（[LURE.md](./LURE.md)）接到物料的口子上，可以用假的竿和线在 Node 里把一整竿走一遍。

`src/shore/startShore.js` 只创建它，并在每帧最前面调用 `fishing.update`、在 `line.update` 之后调用 `fishing.follow`。

## 2. 不能破的规则

**规则只写在这一层。** 物料只报数。竿尖在哪、线多硬是物料给的；甩得够不够算一次抛投、线收到多短算收完，是这里判的。

**只通过口子动物料。** 想让竿受力，改线长或线的远端，不往竿尖加力。镜头只通过 `lockLook` 锁。

**饵不瞬移，线长不跳。** 换段的时候位置和线长接得上。飞行时线带着一点弧，落水以后这点余线在大约半秒里自己收掉，线变直，不在落水那一帧跳成直线。

## 3. 一竿的三段（`fishing.js`）

| 段 | 画面 | 手指按下 | 手指松开 | 怎么出去 |
|---|---|---|---|---|
| `ready` 空杆 | 线收到头，饵贴在竿尖，跟着竿尖走，不晃 | 镜头定住，开始量这一甩。线不出 | 正在向前甩：饵飞出去。否则什么都不发生 | 松手时手机向前倾得够快 → `flight` |
| `flight` 飞行 | 饵在空中，线跟着放 | 出线停下，饵在已经飞出的距离落下 | 不恢复出线 | 饵碰到水面 → `water` |
| `water` 水里 | 饵在水下。线在落水后约半秒内自己变直 | 收线。但落水时就按着的那一下不算，要先松开 | 不收线，饵停在原地 | 线收到头 → `ready` |

- **空杆时饵是固定在竿尖的，不是挂着的。** 甩竿蓄力时竿尖走得很快，挂着的饵会被甩得乱荡，既挡视线又让出手的位置不定。所以这一段不用 `lureMove.hang`：玩法调 `line.stow`，线把远端放在这一帧的竿尖下面，再由 `follow` 把饵摆过去，鼻尖朝上。
- 从 `flight` 开始到回到 `ready`，镜头一直锁着，手机只动竿。
- 回到 `ready` 以后要先松一次手，下一次按下才算新的一竿。收线一直按到底不会直接变成下一次甩竿。
- 落水后线还在变直的那半秒里按住收线，先收掉的是剩下的余线，收完才开始拖饵。这不是需求里排除的"先收一截虚线"：不按它也自己变直，玩家不用为它做任何事。
- 饵靠近到竿尖正下方 1.6 米以内时被线提出水面，之后是挂在线上的重物，会荡；继续按住就一直收到竿尖，收到头就又固定住了。
- 饵在竿尖、在空中、被提起来以后，线不拉竿（`line.setTied(false)`）。只有饵在水里时线系着竿尖。
- 收了多少线就让渔轮转多少（`rod.reel.wind`）。抛出去时线是自己放的，渔轮不转。

| 常量 | 值 | 管什么 |
|---|---|---|
| `STOW_LENGTH` | 0.025 米 | 收好时竿尖外留多长的线：饵的鼻尖正好在竿尖的导环下面。线回到这么长，这一竿结束 |
| `FLIGHT_SPARE` | 0.04 | 飞行时线比两端的距离多放出的比例，线在空中有一点弧 |
| `SETTLE_RATE` | 5 /秒 | 落水后线上的余线收掉的快慢。0.25 秒后剩约四分之一，0.5 秒后剩不到一成。调小线直得更慢 |
| `SETTLE_DONE` | 0.002 米 | 余线小于它就算直了 |
| `LIFT_WITHIN` | 1.6 米 | 饵离竿尖正下方这么近时被提出水面 |
| `NOSE_RATE` | 10 /秒 | 饵的鼻尖转向线的快慢 |
| `NOSE_LEVEL` | 0.25 | 在水里时鼻尖比线平多少 |
| `DESK_FULL_HOLD` | 1 秒 | 只用于桌面：没有传感器时，按住这么久算一次全力的甩 |

## 4. 甩（`swing.js`）

力度是手机向前倾得多快，也就是瞄准的俯仰往下掉的角速度，单位度/秒。读法是让一个值追着俯仰，落后多少就是角速度，不对两帧做差。

**在手上量，不在竿尖量。** 竿身很软，快速一甩时竿尖先落在后面、再弹过去，它的速度反映的是竿身而不是这一甩。用真实的竿模型算过：手以 220°/秒甩，竿尖向前的速度只有约 1.2 米/秒，而且峰值出现在手停下以后。最初的版本量竿尖，结果怎么甩都出不了线。

只算按住以后的甩：手指按下时把读数清零。松手稍晚也算：最近的最大值按 `BEST_FADE` 慢慢退。

方向不由甩决定。按下时镜头已经定住，饵沿镜头的朝向飞出去。

| 常量 | 值 | 管什么 |
|---|---|---|
| `TRAIL_RATE` | 18 /秒 | 追俯仰的值跟得多紧。读到的角速度大约滞后 1/18 秒。调小更稳也更迟，很短促的一甩会读得偏小 |
| `BEST_FADE` | 4 /秒 | 最大值退得多快。调小，甩完以后晚一点松手也还算数 |
| `SWING_MIN` | 90°/秒 | 低于它松手不算抛投 |
| `SWING_FULL` | 420°/秒 | 到这个角速度抛到最远 |
| `REACH_MIN`、`REACH_MAX` | 6、28 米 | 最近和最远的落点，从竿尖正下方算 |

甩完立刻松手：120°/秒抛约 6.5 米，220°/秒约 13 米，400°/秒约 26 米。甩完 0.15 秒才松手，读数剩一半左右：220°/秒只抛约 6.5 米。停下 0.4 秒以后再松手不算抛投。

设置面板最下面的"这一竿"一行实时显示现在在哪一段、线放出多少、正在读到的角速度和上次松手时读到的角速度。它是给调这张表用的，不是给玩家的提示。

## 5. 收（`retrieve.js`）

每一次按下都从头开始：缓起到慢速，保持，再升到匀速，然后一直匀速。不接着上一次的速度。松手时线不是立刻停死，原来的速度很快滑掉；这时再按下，新的一次从零起，和还没滑完的那一点叠在一起，所以线速不会跳。

收了多少线是速度的精确积分，不随帧率变。

| 常量 | 值 | 管什么 |
|---|---|---|
| `SLOW_SPEED` | 0.3 米/秒 | 每次按下开头的慢速 |
| `EASE_IN` | 0.15 秒 | 从 0 到慢速用多久 |
| `SLOW_FOR` | 0.6 秒 | 按下以后多久开始加速 |
| `RISE` | 0.9 秒 | 从慢速升到匀速用多久 |
| `STEADY_SPEED` | 1.2 米/秒 | 匀速。调大饵回来得快，竿上也更重 |
| `COAST_RATE` | 9 /秒 | 松手后线速滑掉的快慢 |

按住 3 秒收 2.63 米。25 米的线收完约 23 秒。

## 6. 和物料的接线

| 物料 | 这一层往里送什么 | 读什么 |
|---|---|---|
| 鱼线 | `setEnd`、`setLength`、`stow`、`setTied` | `tip`、`end`、`stiffness` |
| 饵 | `lureMove` 的 `hang` / `launch` / `fly` / `tow`，`lure.place` | 位置、`swum` |
| 渔轮 | `rod.reel.wind` | — |
| 镜头 | `lockLook(true / false)` | — |
| 手机瞄准 | — | 瞄准的俯仰，经 `startShore` 传进来 |

`update(dt, input)` 的输入由 `startShore` 给：`finger` 手指是否按着，`sensor` 有没有在读手机的姿态，`viewYaw` 镜头朝哪，`aimPitch` 手机把竿瞄得多高（镜头的俯仰加上竿的那一份）。

**每帧调两次。** `update` 在最前面，在 `applyPhone` 和 `rod.update` 之前：松手那一帧就要把镜头锁住，晚一步镜头会先朝竿指的方向追出去一截。代价是它读到的竿尖是上一帧线画出来的那个。`follow` 在 `line.update` 之后：空杆时把饵摆到这一帧的竿尖上，这样饵不会比竿慢一帧。别的段里 `follow` 什么都不做。

**桌面的替身。** 桌面拖动是转镜头，所以手指换成空格键。没有传感器竿不会动，甩的力度用按住的时间代替：按住 1 秒算全力。这只是为了在桌面上把流程走通，手感以真机为准。

`startShore()` 返回的对象上有 `fishing`，可以读 `stage`、`lineOut`、`swing`、`lastRelease` 和 `lure`（饵的位置和速度）。

## 7. 需求里没定、这里先填的

需求第 6 节写"饵一落水，线就是绷直的"。实现是落水后约半秒内自己变直：一帧之内从带弧变成直线，画面上是一次跳变。

这些在 [FISHING-REQUIREMENTS.md](./FISHING-REQUIREMENTS.md) 第 19 节或正文里没有数字，现在的值是试出来之前的起点：

- 多大的甩算抛投，抛多远（第 4 节的表）。
- 空竿收线的慢速、匀速和加速时间（第 5 节的表）。
- 线收到多短算收完：`STOW_LENGTH`。
- 饵游多深：`SWIM_DEPTH`，在 [LURE.md](./LURE.md)。

## 8. 还没做

- 咬口、抬杆、拔河、出线、线断、鱼离水。上钩的鱼从鱼群里取，见 [FISH-SCHOOL.md](./FISH-SCHOOL.md) 第 6 节。
- 落水的涟漪和入水声，每一段的震动。
- 抛投时线挡打开，线从线杯上放出去。
- 甩的方向只取镜头的朝向，往左右甩不会抛偏。
- 抬杆的判定。读法可以照 `swing.js`：量瞄准的俯仰往上走的角速度。

## 9. 改的时候

- 想改一竿怎么走、手指在哪一段是什么意思：改 `fishing.js`，并先改需求文档。
- 想改抛多远、多用力才算：只改 `swing.js` 的常量。
- 想改收线的快慢：只改 `retrieve.js` 的常量。
- 想改饵怎么飞、在水里怎么跟线：不在这里，在 [LURE.md](./LURE.md)。
- 新的规则写成新的文件放在 `src/play/`，只算数的和接线的分开。不要写进 `startShore.js`，也不要写进物料。
- 改完在 Node 里验，见 [CONVENTIONS.md](./CONVENTIONS.md) 第 7 节。
