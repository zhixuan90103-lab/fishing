# 岸边鱼群

状态：已实现。鱼群是物料：它自己随机游；钓鱼玩法从里面取一条鱼，让它游向饵、挂在线上，再放回来，见 [PLAY.md](./PLAY.md)。  
咬口、拔河的规则不在这里，在 [FISHING-REQUIREMENTS.md](./FISHING-REQUIREMENTS.md)。这里只提供会游的鱼和接入的口子。

## 1. 分层

一条鱼每一帧走四步。前三步只决定"想去哪"，只有最后一步真的动。

| 步 | 做什么 | 文件 |
|---|---|---|
| 状态 | 这条鱼现在想干什么，写出目标朝向、速度、深度 | `src/fish/behaviors.js` |
| 习性 | 它自己的游走和窜 | `src/fish/behaviors.js` |
| 归队 | 离鱼群太远就往回靠 | `src/fish/behaviors.js` |
| 游 | 让开同伴、绕石头、转向、前进、身体姿态 | `src/fish/swim.js` |

其余文件：

| 文件 | 职责 |
|---|---|
| `src/fish/shoal.js` | 把鱼群当成一个整体：共同的朝向、深度、快慢节奏。它不画出来 |
| `src/fish/flock.js` | 一帧的流程，把上面几步串起来。不加载、不渲染，可以脱离浏览器跑 |
| `src/fish/hung.js` | 出了水的鱼：嘴在哪，从嘴上怎么挂、怎么甩。见第 7 节 |
| `src/fish/school.js` | 岸边用的入口：取 40 条真鱼交给 `flock`，再播尾巴动画和脊柱波 |
| `src/fish/dorade.js` | 模型、对象池、脊柱姿态 `poseSpine` |
| `src/fish/preview.js` + `fish.html` | 单看一条鱼。有游速、发力、弯身三个滑杆 |

`src/shore/startShore.js` 只负责创建和每帧调用 `update`。

## 2. 两条不能破的规则

**鱼不横移。** 鱼在水平面上只沿自己鼻尖的方向前进。让开同伴、回到鱼群、绕石头，都只能改目标朝向和速度，不能直接挪位置。以后加任何新的力或新的状态，也只能写目标，再由 `swimFish` 游过去。唯一的例外是鱼真的穿进了石头：位置被推出来，同时鱼头转到它实际滑过去的方向。

**动作是连续的。** 目标可以突变，鱼不能。速度、朝向、深度都是朝目标逼近，加速快、减速慢。所以任何状态切换都不会瞬移或突然掉头。

## 3. 鱼群整体（`shoal.js`）

- **位置**：每帧改写成"在群里的鱼"的平均位置。是鱼带着群走，不是群拖着鱼走。
- **快慢**：巡航、冲刺、滑行三段循环。每段的时长和冲刺的强度每一轮重新取。基准速度在游速滑杆为 1 时是 0.351 米/秒。
- **深度**：在 −3.75 到 −1.75 米之间。平游一阵，然后换一层，少数时候小幅上下搜。
- **朝向**：每隔一两秒换一个小的转向意愿。每隔大约 20 到 50 秒无缘由地急拐并冲一下。
- **留在画面里**：按镜头的位置、朝向和视野算出鱼群在画面中的位置。中心留在镜头前方大约 11 到 16 米；靠近边缘就转回来，出了画面转得更急。

出生在镜头前方约 13 米、水深约 −2.7 米，横穿画面。

## 4. 每条鱼

### 状态

每条鱼有一个 `fish.state`。一个状态就是一个函数 `(fish, aim, env, dt)`，写出目标，必要时切到别的状态。

| 状态 | 行为 |
|---|---|
| `school` | 在群里。前方 3.2 米内、左右 0.95 米内有同伴，就跟它的朝向和深度；近于 0.85 米不超过它的速度，远于 1.6 米加速追 |
| `stray` | 离群。和鱼群同向但向一侧偏 9° 到 17°，游 3.5 到 6.5 秒。偏远了或到时间就转回去，离中心 1.15 米以内时并回 `school` |
| `held` | 被外面取走，还在水里，见第 6 节 |
| `hung` | 出了水，挂在线上或躺在网里。不游，见第 7 节 |

40 条里后 20 条是会离群的（`fish.roamer`），每隔 12 到 30 秒离群一次。前 20 条一直在群里。

没有固定线路，也没有固定站位。

### 习性

不在 `held` 状态的鱼都有，每条鱼有自己的节奏：

- **游走**：在目标朝向和深度上叠一个很慢的摆动。
- **窜**：每隔 5 到 22 秒加速不到一秒，可能带一点偏向，然后滑回原来的速度。

每条鱼还有出场时定一次的游速比例（约 0.78 到 1.24）和体型缩放。

**体型只有小、大两段，中间没有。** 小的 0.78 到 0.95（体长约 0.35 到 0.43 米），大的 1.2 到 1.4（约 0.54 到 0.63 米），各占一半，所以在水里一眼分得出来。体型只改模型的缩放和嘴的位置，不改它怎么游。这条鱼被钩住以后有多大力，是玩法按 `fish.size` 去查的，见 [PLAY.md](./PLAY.md) 第 8 节。

| 常量（`flock.js`） | 值 | 管什么 |
|---|---|---|
| `SMALL_SIZE`、`BIG_SIZE` | 0.78 到 0.95、1.2 到 1.4 | 小鱼和大鱼的体型缩放。改了要和 `src/play/fishKind.js` 表里的体型对上 |
| `BIG_SHARE` | 0.5 | 大鱼占几成 |

### 归队

游走和窜会累积，把队伍越拉越散。所以在群里的鱼离中心超过 2.4 米时，朝向往中心偏，落在后面的再加一点速。正在返回的离群鱼做同一件事，力度更大。

## 5. 游（`swim.js`）

`swimFish` 拿到目标之后依次做：

1. **让开同伴**。两条鱼近于 0.95 米算拥挤。拥挤方向里横向的那一份变成转向，前后的那一份变成加速或减速，上下的那一份变成换深度。越挤转得越快。
2. **绕石头**。近处石头（z < 40）当成竖直圆柱。鱼从自己所在的一侧绕；离石头表面 0.6 米时朝向已经完全贴着切线，再近就向外偏。鱼群因此分开，绕过后再汇合。
3. **发力**（`fish.drive`）。正在加速时大，匀速时中等，滑行减速时接近零。
4. **转向、弯身、侧倾**。身体弯向转弯的内侧（`fish.bend`），同时向内侧倾。
5. **前进**。只沿鼻尖方向。
6. **深度和俯仰**。俯仰按实际的上下速度来。

### 身体姿态（`dorade.js` 的 `poseSpine`）

模型自带的动画里，脊柱每节只摆 1° 到 8°，而且各节同相位，看起来是一块板在摆。`poseSpine` 在动画之上给脊柱六节加一道从头向尾传的波，摆幅乘以发力；再把弯身分摊到这六节上。背鳍和腹部的骨骼挂在头部而不是脊柱上，所以它们各自抄同一位置那节脊柱的转角。头不摆。

尾巴动画的播放速度跟这条鱼的实际速度成正比：滑杆 × 2.2 × 实际速度 / 0.351。

要调摆幅，改 `dorade.js` 里 `SPINE` 表的第二列。

## 6. 给玩法留的口子：水里的鱼

`createShoreSchool` 返回的对象上有：

| 接口 | 作用 |
|---|---|
| `fishes` | 40 条鱼。每条有 `x, y, z, yaw, speed, state`，和出场时定下的体型 `size` |
| `take(fish, brain)` | 取走一条。之后每帧由 `brain(fish, aim, env, dt)` 写它的目标 |
| `giveBack(fish)` | 放回。它自己游回鱼群再并进去。还在路上的鱼、线断以后挂着的鱼都走这里 |
| `mouth(fish, out)` | 这条鱼的嘴现在在哪，世界坐标，写进 `out.x, out.y, out.z` |

被取走的鱼不再算进鱼群中心，也不带别的鱼的朝向。它没有游走和窜，完全听 `brain` 的。但它仍然让开同伴、绕石头、只沿鼻尖前进，身体姿态也照常。

`brain` 只许写目标，不要在里面改鱼的位置。游向饵、绕饵、碰钩、外冲、受惊跑远，都是这样的函数，写在玩法那一侧。现在有两个：`src/play/visit.js` 的游向饵，`src/play/fight.js` 的挂在线上。

| 目标 | 是什么 | 不写时 |
|---|---|---|
| `aim.yaw`、`aim.speed`、`aim.y` | 想去的朝向、速度、深度 | 鱼群的朝向、速度、深度 |
| `aim.turn` | 转得多急，1/秒 | 4.2 |
| `aim.accel` | 提速多快，1/秒 | 0.7 |
| `aim.slow` | 减速多快，1/秒。鱼自己是慢慢滑停的；挂在线上的鱼是被线刹住的，要快得多 | 0.22 |
| `aim.rise` | 换深度多快，1/秒 | 0.45 |
| `aim.top` | 最浅能到哪，米。鱼群的水层到 −1.75 米为止；饵可以更浅，来咬它的鱼要能上来 | −1.75 |

后三个目标每帧都先复位成鱼群自己的值，所以没被取走的鱼不受影响。放回的鱼如果还在鱼群的水层上面，不会被一下按回去，是自己游下去的。

**嘴的位置是在模型上量的**：在鱼身中心前面 0.485 个体长、中线下面 0.073 个体长处（`hung.js` 的 `MOUTH_AHEAD`、`MOUTH_BELOW`）。这种鱼的吻端在眼睛的连线下面，不在中线上；只往前不往下，线会连到额头上。

## 7. 出了水的鱼（`hung.js`）

鱼被钓上来以后不在水里，不游。它是线上或网里的一个重物，从嘴上挂着。这是唯一不靠游的情况，和第 2 节的规则不冲突：那两条管的是水里的鱼。

| 接口 | 作用 |
|---|---|
| `hang(fish, mx, my, mz, upX, upY, upZ, dt, vigor, free)` | 把一条取走的鱼从嘴上挂起来，每帧调用。嘴正好在 `(mx, my, mz)`，身子转过去顺着指向 `(up…)` 的线垂着，并且甩。`vigor` 是这一刻甩多用力，1 是平常，不给就是 1。`free` 是它是不是悬空挂在线上：是就绕着线转，躺在网里的传假。不给就是真。状态变成 `hung` |
| `keep(fish)` | 挂着的鱼被带走了（进了抄网、出了画面）。鱼群在画面外、鱼群一侧 `RETURN_SIDE` 处把它收回来，它自己游回来。只在这条鱼看不见的时候调用：这是唯一一处一步挪动鱼的地方 |

`flock.js` 只管换状态和调用，怎么摆在 `hung.js`，它不引 Three，可以对一条假鱼单独跑。

**从游到挂不跳。** 那一刻嘴的位置不变，身子是按 `HANG_TURN` 转过去的。

**不用朝向角记方向。** 出了水的鱼可以指向任何方向，包括正上方。鱼头经过竖直方向时，"朝向"会一下子转半圈，鱼就从肚子翻到背。所以挂着的鱼记的是两个向量：鼻尖朝哪、背朝哪。每帧把鼻尖转一点，背跟着带过去，不绕着鼻尖自转；朝向、俯仰、侧倾三个角是从这两个向量读出来的（`takeFrame`、`turnFrame`、`poseFrame`）。

**它怎么甩。** 三样叠在一起：身子左右弯（`HANG_BEND`），绕着线来回拧（`HANG_TWIST`），整条身子从嘴上左右荡（`HANG_SWING`）。荡是把"线的方向"左右摆一点，身子去追，所以是连续的；弯和拧是读角度时临时叠上去的，不存回去，不会越攒越多。挂得越久甩得越弱，最后剩 `HANG_CALM`。

**悬空挂着时它绕着线转。** 只左右甩的话，朝着镜头的始终是同一面。它的甩动把它往一个方向带（方向挂起来时取一次），线被它拧出来的劲往回拽，空气让它慢下来。所以它不是匀速转：甩得猛时转得快，一条鱼从出水到落网大约转九成圈，力气小下去以后会往回松一点。转过的角度和拧一样单独记着，读角度时叠上去。落进网里以后没有东西可转，剩下的转速很快停掉，停在哪就是哪。

**甩多用力由调用的人给，鱼只管甩成什么样。** `vigor` 把三样的幅度一起放大，各自有上限。它不是一帧加满的，按 `VIGOR_RATE` 加上来：弯和拧直接叠在姿态上，力度一跳鱼就跳。什么时候该猛甩（出水、落网）是玩法定的，见 [PLAY.md](./PLAY.md) 第 10 节。

| 常量（`hung.js`） | 值 | 管什么 |
|---|---|---|
| `MOUTH_AHEAD`、`MOUTH_BELOW` | 0.485、0.073 个体长 | 嘴在鱼身中心前面多远、中线下面多远 |
| `HANG_TURN` | 6 /秒 | 挂起来以后身子转到顺着线有多快 |
| `HANG_BEND`、`HANG_BEAT` | 0.5 弧度、17 弧度/秒 | 弯身的幅度和快慢 |
| `HANG_TWIST` | 0.35 弧度 | 绕着线来回拧多大 |
| `SPIN_DRIVE`、`SPIN_UNWIND`、`SPIN_LOSS` | 3.4、0.18、1.6 | 绕着线转：甩动带它转多猛，线每拧一弧度往回拽多大，空气让它慢多快。第一个调大转得快、转得多 |
| `SPIN_STOPS` | 9 /秒 | 落进网里以后剩下的转速停多快 |
| `HANG_SWING`、`HANG_SWING_BEAT` | 0.2 弧度、7.3 弧度/秒 | 整条身子从嘴上左右荡多大、多快。两个不同步的节拍叠在一起，不会像钟摆 |
| `HANG_TIRE`、`HANG_CALM` | 0.5 /秒、0.35 | 甩得越来越弱有多快，最后剩几成 |
| `BEND_MOST`、`SWING_MOST`、`TWIST_MOST` | 0.85、0.6、0.55 弧度 | 弯、荡、拧各自最多到多大，甩得再用力也不过 |
| `VIGOR_RATE` | 9 /秒 | 更用力的甩多快加上来 |
| `HANG_TAIL` | 0.9 米/秒 | 甩的时候尾巴动画按多快的游速播 |

| 常量（`flock.js`） | 值 | 管什么 |
|---|---|---|
| `RETURN_SIDE` | 11 米 | 被带走的鱼从鱼群一侧多远的地方回来 |

## 8. 资源

一条鲷鱼 GLB，加载一次。对象池克隆 40 条，几何体和材质共用，每条鱼有自己的骨架和动画混合器。`acquire` / `release` 不重新加载，也不销毁。

头在 holder 的局部 +Z。朝向顺序是 YXZ。正的 Y 转向鱼的左侧，正的 X 是低头。

## 9. 改的时候

- 想让鱼"想做"别的事：加状态，或给 `take` 传一个 `brain`。不要动 `swim.js`。
- 想改出了水的鱼怎么甩、嘴在哪：只改 `hung.js`。改完每帧由三个角还原鼻尖和背，量一帧转多少，不能有翻面。
- 想改鱼"怎么游"：只改 `swim.js`，并且守住第 2 节两条规则。
- 想改整群的节奏和走位：只改 `shoal.js`。
- 模型、骨骼、对象池只改 `dorade.js`。热路径不重新加载、不销毁。
- 不要把游动写回 `startShore.js`，也不要写进水面着色器。
- 不改水面外观，不改三层 256² FFT。
- 头仍是局部 +Z。不要把朝向改回 −Z。
- `flock.js` 往下不依赖 Three，可以在 Node 里用固定随机种子跑。改完游动后值得量三件事：运动方向和鱼头朝向的夹角（应为 0）、鱼群散布、两条鱼贴得太近的比例。
