# 岸边鱼群

状态：已实现，2026-11-24 重写了自由的鱼怎么游，真机上还没看过。鱼群是物料：每条鱼自己拿主意，没有人指挥；钓鱼玩法从里面取一条鱼，让它游向饵、挂在线上，再放回来，见 [PLAY.md](./PLAY.md)。  
咬口、拔河的规则不在这里，在 [FISHING-REQUIREMENTS.md](./FISHING-REQUIREMENTS.md)。这里只提供会游的鱼和接入的口子。

## 1. 分层

没有"鱼群"这个东西，只有四十条鱼。一条鱼每一帧走三步，前两步只决定"想去哪"，只有最后一步真的动。

| 步 | 做什么 | 文件 |
|---|---|---|
| 看 | 身边的鱼往哪游、多快、多深，看得见的鱼在哪边，旁边有没有鱼刚窜出去 | `src/fish/neighbours.js` |
| 想 | 这条鱼自己拿主意，写出目标朝向、速度、深度。被取走的鱼这一步换成玩法给的 `brain` | `src/fish/behaviors.js` |
| 游 | 让开同伴、绕石头、转向、前进、身体姿态 | `src/fish/swim.js` |

其余文件：

| 文件 | 职责 |
|---|---|
| `src/fish/homeWater.js` | 鱼待的那片水：在哪，一条鱼在某处有多不自在、哪边是回去的方向 |
| `src/fish/states.js` | 三种状态的名字：`free`、`held`、`hung` |
| `src/fish/flock.js` | 一帧的流程，把上面几步串起来，以及给玩法的口子。不加载、不渲染，可以脱离浏览器跑 |
| `src/fish/hung.js` | 出了水的鱼：嘴在哪，从嘴上怎么挂、怎么甩。见第 7 节 |
| `src/fish/school.js` | 岸边用的入口：取 40 条真鱼交给 `flock`，再播尾巴动画和脊柱波 |
| `src/fish/dorade.js` | 模型、对象池、脊柱姿态 `poseSpine` |
| `src/fish/preview.js` + `fish.html` | 单看一条鱼。有游速、发力、弯身三个滑杆 |

`src/shore/startShore.js` 只负责创建和每帧调用 `update`。

## 2. 三条不能破的规则

**鱼不横移。** 鱼在水平面上只沿自己鼻尖的方向前进。让开同伴、靠向同伴、绕石头，都只能改目标朝向和速度，不能直接挪位置。以后加任何新的力或新的状态，也只能写目标，再由 `swimFish` 游过去。唯一的例外是鱼真的穿进了石头：位置被推出来，同时鱼头转到它实际滑过去的方向。

**动作是连续的。** 目标可以突变，鱼不能。速度、朝向、深度都是朝目标逼近，加速快、减速慢。所以任何状态切换都不会瞬移或突然掉头。

**没有人指挥鱼群。** 2026-11-24 定。没有整群的朝向、深度、节奏，没有鱼群中心，没有带头的鱼。一条鱼只知道它自己看得见的东西。成群、一起转向、散开又合拢、换水层、有一条独自游开，都没有写在任何地方，是四十条不一样的鱼各自这样做出来的。想让鱼群"多做一件事"时，先问它是哪一条鱼看到了什么、怎么反应，不加整群的规则，也不加整群共用的钟。依据在 [FISH-SWIM-RESEARCH.md](./FISH-SWIM-RESEARCH.md)"群怎么从个体里长出来"。

在这之前的做法（2026-11-17 到 11-20）：有一个 `shoal.js` 管整群的朝向（隔 20 到 50 秒安排一次急拐）、深度（平游、换层、上下搜三段轮换）和活跃度；每条鱼按自己的钟巡航、冲刺、滑行；一半的鱼按固定周期离群再回来；所有鱼被拉向鱼群中心。看着像编好的节目，整个去掉了。

## 3. 一条鱼知道什么

### 身边的鱼（`neighbours.js`）

| 它知道 | 怎么来的 |
|---|---|
| 近处的鱼往哪游、多快、多深 | 3.2 米（`SEE`）以内的鱼，越近算得越重 |
| 近处有多少同伴 | 同上的权重加起来：贴身的一条算将近 1，刚看得清的算 0 |
| 看得见的鱼在哪边 | 12 米（`SEE_FAR`）以内、又远于 1.1 米（`SPACING`）的鱼的方向。越远越不在意 |
| 旁边有没有鱼刚窜出去 | 1.5 米（`ALARM_RANGE`）以内正在窜的鱼有几条 |

正后方的鱼它看不见（`BLIND`）。上下差一米按 1.6 米算（`DEPTH_COUNTS`），所以群是扁的。被取走的鱼谁也不把它当同伴：挂在线上的鱼不会带着别的鱼跑。靠得太近要让开是另一件事，在 `swim.js`（第 5 节）。

### 它待的那片水（`homeWater.js`）

镜头前方 24 米为中心的一个椭圆：前后各 5 米，左右到画面边的九成。它不是墙。中间六成（`CALM`）里鱼什么也感觉不到；越靠边越不自在，到边上是 1，出去以后照同样的斜率接着涨。所以被线拖到二十米外的鱼，放开以后自己会回来。

这片水跟的是设置里的镜头位置和朝向，不跟手机转动的视线。场景里没有海底，"这片水"是替"它们住在这一带"顶着的：真鱼守着的是礁石、水深和食物。

| 常量（`homeWater.js`） | 值 | 管什么 |
|---|---|---|
| `AHEAD` | 24 米 | 这片水的中心在镜头前方多远 |
| `HALF_DEEP`、`SIDE_SHARE` | 5 米、0.9 | 前后各多远；左右到画面边的几成 |
| `CALM` | 0.6 | 中间几成是完全自在的。调大鱼散得开，也更常游到画面边 |
| `START_DEPTH` | −2.7 米 | 出生的深度 |

出生时散在中心周围大约 8 米长、8 米宽、1.6 米深的一团里，横穿画面，只为互不重叠，之后没有固定站位。

## 4. 每条鱼怎么拿主意（`behaviors.js`）

### 状态

| 状态 | 谁写它的目标 |
|---|---|
| `free` | 它自己，见下 |
| `held` | 被外面取走，还在水里，由 `brain` 写，见第 6 节 |
| `hung` | 出了水，挂在线上或躺在网里。不游，见第 7 节 |

### 朝哪游

五样东西各是一个方向，按分量加起来，合成的方向就是它想去的方向：

| 来源 | 分量 | 是什么 |
|---|---|---|
| 它自己 | 1 | 照现在的方向接着游，左右慢慢偏一点（`MEANDER`，每条鱼三个互不同步的慢波） |
| 邻居的朝向 | `ALIGN` 0.8 × 合群 | 近处的鱼往哪游，它也往哪游 |
| 靠向同伴 | `COHERE` 1.6 × 合群 ×（1 − 同伴数 ÷ `COMPANY`） | 朝看得见、又离得远的鱼靠。身边同伴够了（1.6）就不再往里挤 |
| 一个念头 | `NOTION` 1.6 | 偶尔想去这片水里的某个地方看看 |
| 这片水 | `HOME` 2.6 × 不自在 | 靠边了往回转。不自在最多算到 `HOME_MOST` 2.5 |

让开贴得太近的鱼是第六样，在 `swim.js` 里加。

**多数鱼没有念头，只是跟着邻居。** 两成的鱼胆大（`BOLD_SHARE`），大约每 15 秒起一个念头；其余的大约每 160 秒一个。念头是这片水中间的一个随机地点和一个随机深度。到了（1.4 米以内）就结束，它到的那个深度成了它以后喜欢的深度；没到，大约 28 秒后自己放弃。少数有想法的鱼就这样把别的鱼带过去，没有谁知道是谁在带（Couzin 等 2005）。整群的转向和换水层是这么来的。

**"偶尔"都是按概率，不是按钟。** 每条鱼每一刻有一个很小的机会，所以没有周期，各帧率下也一样。

### 多深

它有自己喜欢的深度，上下慢慢漂一点（`LEVEL_DRIFT`）。身边有同伴时往它们的深度靠，合群的靠得多（`LEVEL_WITH_OTHERS` 0.75）。有念头时去念头的深度。

### 多快

- **不紧不慢时每秒游 0.78 个身长**（`CRUISE_LENGTHS`），每条鱼再乘自己的快慢 0.8 到 1.2（`PACE`），也就是 0.62 到 0.94 个身长。所以大鱼每秒走得比小鱼远：小鱼约 0.22 到 0.40 米，大鱼约 0.34 到 0.59 米。
- 照实的依据和没查到的：金头鲷自发游只在小水槽里量过（18 厘米的鱼、直径 40 厘米的槽），不超过每秒 0.5 个身长，论文自己说可能被容器限制；硬骨鱼平时游动常见的范围是 0.5 到 1 个身长（转述 Videler 1993，二手）；野外巡游没有查到直接测量。这里取的是这个范围的中上段，不算为了好看偏快。见 [FISH-SWIM-RESEARCH.md](./FISH-SWIM-RESEARCH.md)。
- 往邻居的速度靠一半（`MATCH_SPEED`，再乘合群）。
- 同伴在前面就加快追，最多六成（`CATCH_UP`）；同伴在后面就慢下来等，最多三成（`WAIT_UP`）。身边同伴够了这两样都没有。
- 在这片水的边上、又正朝里游，加快最多五成（`HURRY_HOME`）。
- **打几下尾、滑一段。** 它一直打尾到比想要的速度快 8%（`KICK_TO`），然后不打了，滑到慢 10%（`GLIDE_TO`）再打。打的时候目标定高三成，滑的时候定低四成。没有计时：什么时候换只看它自己现在多快。每条鱼的这两条线略有不同。

### 窜

一下短促的猛蹬：0.4 到 0.9 秒，快 1.6 到 2.5 倍，方向偏最多 0.35 弧度。它要有原因，每个原因是一个每秒的机会：

| 原因 | 机会 |
|---|---|
| 被挤着（拥挤超过 `SQUEEZED` 0.55） | 每超出 1，每秒 0.5（`BOLT_SQUEEZED`） |
| 旁边的鱼窜了 | 每条每秒 0.9（`BOLT_ALARM`）。一条窜会带起旁边几条 |
| 看得见别的鱼、身边却一条都没有 | 每秒 0.12（`BOLT_ALONE`） |

窜完要缓 3 到 7 秒（`BOLT_SPENT`），这段时间它不会再窜，所以一串带起来的窜会自己停下。2026-11-24 以前每条鱼每 5 到 22 秒无缘无故窜一次；改成有原因以后，每条鱼每分钟窜一到两次，水面平静时比以前安分。

### 每条鱼不一样的地方

出场时各取一次，以后不变（`seedNature`）：

| 性子 | 范围 | 管什么 |
|---|---|---|
| 体型 `size` | 小 0.78 到 0.95，大 1.2 到 1.4，各一半 | 模型缩放、嘴的位置、游多快；合群也跟着它 |
| 合群 `social` | 0.22 到 1 | 体型 1 的鱼是 0.74，每大 1 减 0.75，再各自上下 0.15。小鱼约 0.65 到 1，大鱼约 0.3 到 0.75。这种鱼大的更常独来独往（FishEthoBase 档案） |
| 胆大 `bold` | 两成的鱼 | 起念头多勤 |
| 快慢 `pace` | 0.8 到 1.2 | 它自己的巡游速度 |
| 游走的幅度和节奏 | 各不相同 | 左右偏多少、上下漂多少 |

**体型只有小、大两段，中间没有。** 小的体长约 0.35 到 0.43 米，大的约 0.54 到 0.63 米，所以在水里一眼分得出来。这条鱼被钩住以后有多大力，是玩法按 `fish.size` 去查的，见 [PLAY.md](./PLAY.md) 第 8 节。

| 常量（`flock.js`） | 值 | 管什么 |
|---|---|---|
| `SMALL_SIZE`、`BIG_SIZE` | 0.78 到 0.95、1.2 到 1.4 | 小鱼和大鱼的体型缩放。改了要和 `src/play/fishKind.js` 表里的体型对上 |
| `BIG_SHARE` | 0.5 | 大鱼占几成 |

### 量到的样子

2026-11-24，Node 里四十条鱼自己游 3 到 5 分钟，几个随机种子，20、60、120 帧：

| 量什么 | 结果 |
|---|---|
| 运动方向和鱼头的夹角 | 0 |
| 离这片水的中心最远 | 边界的 0.9 倍上下；半数时间在 0.5 以内 |
| 最近的同伴 | 中位 0.74 米，九成五在 1.1 米以内；没有鱼落到看不见同伴 |
| 速度 | 中位每秒 0.83 个身长，九成在 1.2 以内 |
| 朝向有多齐（1 是全体同向） | 中位 0.73 到 0.81，低的时候 0.5，高的时候 0.9：有时一起走，有时散着 |
| 深度 | 八成在 −3.2 到 −2.3 米之间，没有鱼贴在上下限 |
| 窜 | 每条鱼每分钟约 1.5 次 |
| 各帧率 | 上面这些数相差在一成以内 |

这些数只说明它没有出错，不说明好不好看。好不好看要在真机上看，还没有看过。

## 5. 游（`swim.js`）

`swimFish` 拿到目标之后依次做：

1. **让开同伴**。两条鱼近于 0.95 米算拥挤。拥挤方向里横向的那一份变成转向，前后的那一份变成加速或减速，上下的那一份变成换深度。越挤转得越快。
2. **绕石头**。近处石头（z < 40）当成竖直圆柱。鱼从自己所在的一侧绕；离石头表面 0.6 米时朝向已经完全贴着切线，再近就向外偏。鱼群因此分开，绕过后再汇合。
3. **发力**（`fish.drive`）。正在加速时大，匀速时中等，滑行减速时接近零。取走它的人如果说了它多使劲（`aim.effort`，0 到 1），发力只按这个数走：0 是 `DRIVE_IDLE`，1 是 `DRIVE_FLAT_OUT`，和它游多快、还想不想加速都没关系。
4. **转向、弯身、侧倾**。身体弯向转弯的内侧（`fish.bend`），同时向内侧倾。
5. **前进**。只沿鼻尖方向。
6. **深度和俯仰**。俯仰按实际的上下速度来。

### 身体姿态（`dorade.js` 的 `poseSpine`）

模型自带的动画里，脊柱每节只摆 1° 到 8°，而且各节同相位，看起来是一块板在摆。`poseSpine` 在动画之上给脊柱六节加一道从头向尾传的波，摆幅乘以发力；再把弯身分摊到这六节上。背鳍和腹部的骨骼挂在头部而不是脊柱上，所以它们各自抄同一位置那节脊柱的转角。头不摆。

尾巴动画的播放速度跟 `fish.stroke` 成正比：滑杆 × 2.2 × `stroke` / 0.351。`stroke` 平时就是这条鱼的实际速度；说了多使劲的鱼，至少按"使劲 × `STROKE_FLAT_OUT`"来摆，所以被线拉住、游不动的鱼尾巴照样打得快。

| 常量（`swim.js`） | 值 | 管什么 |
|---|---|---|
| `DRIVE_IDLE`、`DRIVE_FLAT_OUT` | 0.12、1.3 | 说了多使劲的鱼，一点不使劲和用尽全力时的发力。巡游是 0.55 |
| `STROKE_FLAT_OUT` | 1.4 米/秒 | 用尽全力时，尾巴至少按游这么快来摆。巡游是 0.35 米/秒 |

要调摆幅，改 `dorade.js` 里 `SPINE` 表的第二列。

## 6. 给玩法留的口子：水里的鱼

`createShoreSchool` 返回的对象上有：

| 接口 | 作用 |
|---|---|
| `fishes` | 40 条鱼。每条有 `x, y, z, yaw, speed, state`，和出场时定下的体型 `size` |
| `take(fish, brain)` | 取走一条。之后每帧由 `brain(fish, aim, env, dt)` 写它的目标 |
| `giveBack(fish)` | 放回。它就地变回一条自己拿主意的鱼：在这片水外面它想回去，看见别的鱼就靠过去，没有谁去接它。还在路上的鱼、线被带光以后挂着的鱼都走这里 |
| `mouth(fish, out)` | 这条鱼的嘴现在在哪，世界坐标，写进 `out.x, out.y, out.z` |

被取走的鱼别的鱼不把它当同伴，不跟它的朝向，也不朝它靠。它没有游走、念头和窜，完全听 `brain` 的。但它仍然让开同伴、绕石头、只沿鼻尖前进，身体姿态也照常。

`brain` 只许写目标，不要在里面改鱼的位置。鱼自己游的那一份只沿鼻尖；被线拖着走是另写的一个目标（`aim.towX`、`aim.towZ`），真正挪位置的仍只有 `swimFish`。游向饵、绕饵、碰钩、外冲、受惊跑远，都是这样的函数，写在玩法那一侧。现在有两个，都由 `src/play/catch.js` 交进来：游向饵的，目标由 `visit.js` 写；挂在线上的，由 `fight.js`、`course.js` 两个文件的答案拼成，`fight.js` 的 `steer` 写目标。

| 目标 | 是什么 | 不写时 |
|---|---|---|
| `aim.yaw`、`aim.speed`、`aim.y` | 想去的朝向、速度、深度 | 它现在的朝向、它不紧不慢的速度、它现在的深度 |
| `aim.turn` | 转得多急，1/秒 | 4.2 |
| `aim.accel` | 提速多快，1/秒 | 0.7 |
| `aim.slow` | 减速多快，1/秒。鱼自己是慢慢滑停的；挂在线上的鱼是被线刹住的，要快得多 | 0.22 |
| `aim.rise` | 换深度多快，1/秒 | 0.45 |
| `aim.top` | 最浅能到哪，米。鱼群的水层到 −1.75 米为止；饵可以更浅，来咬它的鱼要能上来 | −1.75 |
| `aim.towX`、`aim.towZ` | 线把它整条拖着走的速度，米/秒，不管它头朝哪。只给钩住的鱼用，方向只朝竿尖。`swim.js` 按 `TOW_RATE`（8 /秒）缓着加上、缓着撤掉，不一帧到位 | 0 |
| `aim.effort` | 它多使劲，0 到 1，和游多快无关。尾巴按它摆多大、至少多快，见第 5 节。挂在线上的鱼由玩法按它这一刻的力给 | 不说（`null`）：尾巴跟着它还想加速多少 |

后四个目标每帧都先复位成自由的鱼用的值，所以没被取走的鱼不受影响。放回的鱼如果还在鱼群的水层上面，不会被一下按回去，是自己游下去的。

**嘴的位置是在模型上量的**：在鱼身中心前面 0.485 个体长、中线下面 0.073 个体长处（`hung.js` 的 `MOUTH_AHEAD`、`MOUTH_BELOW`）。这种鱼的吻端在眼睛的连线下面，不在中线上；只往前不往下，线会连到额头上。

## 7. 出了水的鱼（`hung.js`）

鱼被钓上来以后不在水里，不游。它是线上或网里的一个重物，从嘴上挂着。这是唯一不靠游的情况，和第 2 节的规则不冲突：那两条管的是水里的鱼。

| 接口 | 作用 |
|---|---|
| `hang(fish, mx, my, mz, upX, upY, upZ, dt, vigor, free)` | 把一条取走的鱼从嘴上挂起来，每帧调用。嘴正好在 `(mx, my, mz)`，身子转过去顺着指向 `(up…)` 的线垂着，并且甩。`vigor` 是这一刻甩多用力，1 是平常，不给就是 1。`free` 是它是不是悬空挂在线上：是就绕着线转，躺在网里的传假。不给就是真。状态变成 `hung` |
| `keep(fish)` | 挂着的鱼被带走了（进了抄网、出了画面）。它被放到画面外、那片水一侧 `RETURN_SIDE` 处，自己游回来。只在这条鱼看不见的时候调用：这是唯一一处一步挪动鱼的地方 |

`flock.js` 只管换状态和调用，怎么摆在 `hung.js`，它不引 Three，可以对一条假鱼单独跑。

**从游到挂不跳。** 那一刻嘴的位置不变，身子是按 `HANG_TURN` 转过去的。

**不用朝向角记方向。** 出了水的鱼可以指向任何方向，包括正上方。鱼头经过竖直方向时，"朝向"会一下子转半圈，鱼就从肚子翻到背。所以挂着的鱼记的是两个向量：鼻尖朝哪、背朝哪。每帧把鼻尖转一点，背跟着带过去，不绕着鼻尖自转；朝向、俯仰、侧倾三个角是从这两个向量读出来的（`takeFrame`、`turnFrame`、`poseFrame`）。

**它怎么甩。** 三样叠在一起：身子左右弯（`HANG_BEND`），绕着线来回拧（`HANG_TWIST`），整条身子从嘴上左右荡（`HANG_SWING`）。荡是把"线的方向"左右摆一点，身子去追，所以是连续的；弯和拧是读角度时临时叠上去的，不存回去，不会越攒越多。挂得越久甩得越弱，最后剩 `HANG_CALM`。

**悬空挂着时它绕着线转。** 只左右甩的话，朝着镜头的始终是同一面。它的甩动把它往一个方向带（方向挂起来时取一次），线被它拧出来的劲往回拽，空气让它慢下来。所以它不是匀速转：甩得猛时转得快，一条鱼从出水到落网大约转九成圈，力气小下去以后会往回松一点。转过的角度和拧一样单独记着，读角度时叠上去。落进网里以后没有东西可转，剩下的转速很快停掉，停在哪就是哪。

**甩多用力由调用的人给，鱼只管甩成什么样。** `vigor` 把三样的幅度一起放大，各自有上限。它不是一帧加满的，按 `VIGOR_RATE` 加上来：弯和拧直接叠在姿态上，力度一跳鱼就跳。什么时候该猛甩（出水、落网）是玩法定的，见 [PLAY.md](./PLAY.md) 第 10 节。

| 常量（`hung.js`） | 值 | 管什么 |
|---|---|---|
| `MOUTH_AHEAD`、`MOUTH_BELOW` | 0.485、0.073 个体长 | 嘴在鱼身中心前面多远、中线下面多远 |
| `HANG_TURN` | 6 /秒 | 挂起来以后身子转到顺着线有多快 |
| `HANG_BEND`、`HANG_BEAT` | 0.5 弧度、17 弧度/秒 | 弯身的幅度和快慢 |
| `HANG_TWIST` | 0.35 弧度 | 绕着线来回拧多大 |
| `SPIN_DRIVE`、`SPIN_UNWIND`、`SPIN_LOSS` | 3.4、0.18、1.6 | 绕着线转：甩动带它转多猛，线每拧一弧度往回拽多大，空气让它慢多快。第一个调大转得快、转得多 |
| `SPIN_STOPS` | 9 /秒 | 落进网里以后剩下的转速停多快 |
| `HANG_SWING`、`HANG_SWING_BEAT` | 0.2 弧度、7.3 弧度/秒 | 整条身子从嘴上左右荡多大、多快。两个不同步的节拍叠在一起，不会像钟摆 |
| `HANG_TIRE`、`HANG_CALM` | 0.5 /秒、0.35 | 甩得越来越弱有多快，最后剩几成 |
| `BEND_MOST`、`SWING_MOST`、`TWIST_MOST` | 0.85、0.6、0.55 弧度 | 弯、荡、拧各自最多到多大，甩得再用力也不过 |
| `VIGOR_RATE` | 9 /秒 | 更用力的甩多快加上来 |
| `HANG_TAIL` | 0.9 米/秒 | 甩的时候尾巴动画按多快的游速播 |

| 常量（`flock.js`） | 值 | 管什么 |
|---|---|---|
| `RETURN_SIDE` | 11 米 | 被带走的鱼从那片水的中心一侧多远的地方回来 |

## 8. 资源

一条鲷鱼 GLB，加载一次。对象池克隆 40 条，几何体和材质共用，每条鱼有自己的骨架和动画混合器。`acquire` / `release` 不重新加载，也不销毁。

头在 holder 的局部 +Z。朝向顺序是 YXZ。正的 Y 转向鱼的左侧，正的 X 是低头。

## 9. 改的时候

- 想让被取走的鱼"想做"别的事：给 `take` 传一个 `brain`。不要动 `swim.js`。
- 想让自由的鱼多做一件事：先问它是哪一条鱼看到了什么。它看到的东西加在 `neighbours.js`，它怎么反应加在 `behaviors.js`。不加整群的规则和整群共用的钟（第 2 节）。
- 想改出了水的鱼怎么甩、嘴在哪：只改 `hung.js`。改完每帧由三个角还原鼻尖和背，量一帧转多少，不能有翻面。
- 想改鱼"怎么游"：只改 `swim.js`，并且守住第 2 节两条规则。
- 想改群的松紧和齐不齐：改 `behaviors.js` 顶上的分量（`ALIGN`、`COHERE`、`COMPANY`）和 `MEANDER`。想改它们待在哪、散多开：改 `homeWater.js`。改完跑 `npm run check school`，再看第 4 节"量到的样子"那张表变了多少。
- 模型、骨骼、对象池只改 `dorade.js`。热路径不重新加载、不销毁。
- 不要把游动写回 `startShore.js`，也不要写进水面着色器。
- 不改水面外观，不改三层 256² FFT。
- 头仍是局部 +Z。不要把朝向改回 −Z。
- `flock.js` 往下不依赖 Three，可以在 Node 里跑；随机数从 `createFlock` 的 `random` 给，同一个种子原样重跑（`hung.js` 里还有一处直接用 `Math.random`）。常驻检查里有两项守着自由的鱼：`school: left alone…` 和 `school: a fish let go far off…`。
