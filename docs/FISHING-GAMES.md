# 同类游戏里，靠竿钓鱼的优缺点

整理自 2026-11-19 的三轮检索。只保留打开过、并且支撑某一条优缺点的来源。商店文案单独标出，没有玩家评价的不写成已经做到。

配套：[FISHING-REQUIREMENTS.md](./FISHING-REQUIREMENTS.md) 是本版需求。[FISHING-FEEL.md](./FISHING-FEEL.md) 是真实钓鱼的手感材料。本文不改那两份。

要对照的感受：玩家靠竿的弯、手上的重量和颤、以及声音来钓鱼。手感要拟真，让人觉得自己在钓。一种鱼、一根竿只是现在的范围，不用来判断这些游戏成败。

## 1. 优点

这些是别的游戏里已经有人做到、并且和上面的感受对得上的地方。

| 优点 | 在哪看到 | 来源 |
|---|---|---|

## 2. 缺点

## 3. 还没被玩家证实的

- *Ultimate Fishing Simulator 2* 在 2025-05-31 把出线改成「拉力超过卷线器公斤数乘泄力」，竿的弯力也按这个算。官方写这应该更真实、更吃技术，并承认每个人对泄力和搏鱼的感觉不同。这次改完之后玩家怎么说，没有打开到。[Steam 新闻](https://store.steampowered.com/news/app/1136380/view/508455949840681326)
- *Cast & Reel* 和 *TiltCast* 的做法最接近「手机就是竿，靠这一口和这一冲来钓」。只有商店说明，没有玩家长评。

## 5. 对照本工程

2026-11-19 按第 1、2 节看过现在的玩法和竿。细节在 [PLAY.md](./PLAY.md)。这里只记对照结果，不改规则。

已经避开的：

- 给玩家的字只有「线断了」。张力、鱼的力、手上叠的力在设置面板的「这一竿」里，是调手感的读数，不是搏鱼界面。
- 竿的弯由线的远端和线长拉出来。手多吃力按线上扛的力算：鱼的力加上把它领回来的那一份，最多到渔轮让线的那个数。所以竿弯多深和手多吃力说的是同一件事。
- 搏鱼看得见鱼和线。镜头跟着鱼，并把竿尖留在画面里。
- 每一冲都带一点侧向，出线时还会折返。横着贴岸跑是少数。
- 小鱼的冲击始终低于出线点。断线只出现在最大那档、气力还足、又一直按着的时候，大约两成。

还在的：

- 小鱼按着收线时，收线的张力和它冲的力差不多，深弯和浅弯叠在一起。能分开的只剩甩头的顿还在不在。2026-11-19 定：这不算要修的。冲和歇差多少只看力差多少，力照实传到竿和手上，小到分不出就是分不出，不为它另写逻辑。见 [PLAY.md](./PLAY.md) 第 14 节。
- 最大那档一直硬顶，大约两成会断。要不要断线还没定，先保留现在的样子，不调。
- 弯和颤只在 Node 和桌面页面里对过，真机还没确认。竿放得低、鱼又远时，再大的力也只多弯一点。真机上若看不出弯，手上就只剩震动。
- 鱼在冲的时候按住仍然是在收：线出的时候收不动，按住变成硬顶。玩家要先从深弯、点头和手颤上读出「现在在冲」，这个取舍才成立。小鱼这一段读不出来，但小鱼不出线，也就没有硬顶。

还没做的：

- 一口的时机。轻咬、中咬、重咬、咬死，抬早了拉出嘴、抬晚了吐饵，都没有。现在嘴一碰到饵就钩住，是替身。
- 抬竿的高低还不改变传到线上的力。侧向带竿已经有了，而且只有鱼不使劲时才领得动。
- 向上抬当作刺钩还没有。轻啄和重口在手上不一样，也还没有对应的一口。
