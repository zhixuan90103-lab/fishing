# 抄网

状态：已实现。抄网是物料：一个圈、一个网兜、一根柄，代码建模。它自己不动，也不知道什么时候该出来。  
什么时候叫它、它走到哪算这一竿结束，是玩法的事，见 [PLAY.md](./PLAY.md) 第 10 节。

## 1. 分层

| 文件 | 回答什么 |
|---|---|
| `src/play/scoop.js` | 抄网的圈随时间走到哪；鱼什么时候脱钩、怎么落进网兜；网被砸得沉下去多少、网兜被坠长多少、晃多大；带着鱼出去。不引 Three，可以在 Node 里跑 |
| `src/shore/net.js` | 模型，以及把它摆到一个点上、柄朝一个方向、网兜拉多长、晃多少 |

数据只往一个方向走：玩法叫网、每帧给鱼嘴的位置 → `scoop` 算出圈在哪、鱼在哪、网兜什么样 → 玩法把这些交给 `net.place` 和鱼群的 `hang`。`scoop` 不知道模型，`net.js` 不知道它为什么在那里。路径写在 `src/play/`，因为"鱼落进网、被带出画面"是这一竿怎么结束的规则。鱼在网里甩多用力是 `kick.js` 定的，甩成什么样是鱼的事，在 [FISH-SCHOOL.md](./FISH-SCHOOL.md) 第 7 节。

## 2. 不能破的规则

**网不瞬移。** 它从画面外进来，出画面以后才藏起来。路径的每一段都是时间的函数，两头缓起缓停。

**鱼还挂在线上时，网跟着鱼。** 进来和等着这两段，每帧按鱼嘴当时的位置算，鱼在荡，网也跟着。鱼脱钩以后网不再看线上的那个点。

**脱钩的那一刻鱼不跳。** 它从嘴当时的位置开始往下落，落的时候往圈的中心靠。

**帧率不改变结果。** 下落按整帧精确积分，落进网的那一刻解到帧的中间。圈的回弹用固定步长 1/240 秒。20 到 120 帧下落网的速度、圈沉下去多少一样。

## 3. 路径和落网（`scoop.js`）

| 段 | 做什么 | 多久 |
|---|---|---|
| `in` | 从鱼的一侧、下方进到鱼尾下面 | `IN_FOR` |
| `wait` | 在鱼下面等一下 | `WAIT_FOR` |
| `fall` | 鱼脱钩，尾巴朝下落进网兜。从这里起 `dropped` 为真：鱼在 `fishX, fishY, fishZ` | 约 0.37 秒，由高度定 |
| `catch` | 鱼在网兜里。圈被砸得一沉，弹回来；网兜被坠长，左右晃；网被端起来一点 | `CATCH_FOR` |
| `out` | 带着鱼从来的那一侧退出去，出画面 | `OUT_FOR` |

`begin(鱼嘴 x, y, z, 侧向 x, z)` 叫网，侧向是水平的单位向量，网从这一侧来、也从这一侧走。`step(dt, 鱼嘴 x, y, z)` 每帧一次，网走完的那一帧返回 `true`。落网的那一帧 `landing` 为真，`landedSpeed` 是当时的速度。

- **圈沉下去**：落网速度的 `DIP_SHARE` 交给圈，圈是一个有阻尼的弹簧，沉约 5 厘米，弹一两下收住。
- **网兜坠长**：有鱼以后长 `BAG_STRETCH`，圈每沉一米再长 `BAG_PER_DIP`。`stretch` 报这个数，1 是没坠。
- **网兜晃**：落网时晃得最大，很快退到 `ROCK_STAYS` 这个比例，鱼在里面甩的时候一直留着。`rock` 报这个角度。
- **鱼在网兜里的位置**：嘴在圈下面 `REST_BELOW`，跟着圈和网兜一起动。

| 常量 | 值 | 管什么 |
|---|---|---|
| `OFF_SIDE`、`OFF_BELOW` | 1.7、1.1 米 | 网在画面外等着和退出去的地方：离鱼的侧向距离，比鱼嘴低多少。要够远，在画面外 |
| `UNDER` | 0.56 米 | 网停在鱼嘴下面多远。要在鱼尾下面，不碰到鱼 |
| `REST_BELOW` | 0.13 米 | 鱼在网兜里时嘴比圈低多少 |
| `IN_FOR`、`WAIT_FOR`、`CATCH_FOR`、`OUT_FOR` | 0.75、0.18、1.1、0.85 秒 | 进来、等、鱼在网里展示、出去各多久 |
| `RAISE`、`RAISE_FOR` | 0.34 米、0.6 秒 | 鱼进网以后把网端起来多少、用多久。端起来才不被画面下边切掉 |
| `CENTRE_RATE` | 9 /秒 | 鱼下落时往圈中心靠多快 |
| `DIP_SHARE`、`DIP_RATE`、`DIP_DAMPING` | 0.3、15 弧度/秒、0.3 | 落网的速度有几成交给圈；圈弹回来多快；阻尼比，1 是不弹 |
| `BAG_STRETCH`、`BAG_PER_DIP`、`STRETCH_RATE` | 0.1、1.6 /米、14 /秒 | 网兜被坠长多少、圈每沉一米再长多少、坠长得多快 |
| `ROCK`、`ROCK_BEAT`、`ROCK_FADE`、`ROCK_STAYS` | 0.2 弧度、10 弧度/秒、2.2 /秒、0.3 | 网兜晃多大、多快、退得多快、留几成 |

在 Node 里量：落网速度 3.7 米/秒，圈沉 5 厘米，网兜最长到 1.14 倍，从叫网到网出画面 3.3 秒。

## 4. 模型（`net.js`）

局部坐标：原点是圈的中心，+Y 朝上（网口朝上），柄沿 +X。圈始终是水平的。

- 圈是一个细圆环。网兜是一条轮廓绕圈的轴转出来的，只画它的棱，所以看得见里面的鱼。
- 柄从圈边出去，略往下垂，末端有一段握把。
- `place(x, y, z, hx, hz, stretch, rock)`：圈的中心放在这个点，柄朝水平方向 `(hx, hz)`；网兜沿竖直方向拉长到 `stretch` 倍，绕柄的方向摆 `rock` 弧度。调用它网就显示。`hide()` 藏起来。

| 常量 | 值 | 管什么 |
|---|---|---|
| `HOOP_RADIUS`、`RIM` | 0.23、0.007 米 | 圈的半径和粗细 |
| `BAG_DEPTH` | 0.62 米 | 网兜多深。0.45 米的鱼吊着嘴放得进去 |
| `BAG` | 表 | 网兜的轮廓，`[半径占圈的几成, 深度占几成]`。改形状就是改它 |
| `AROUND` | 18 | 网眼绕一圈分多少格 |
| `HANDLE`、`HANDLE_RADIUS`、`HANDLE_DROOP` | 1.3 米、0.011 米、0.3 弧度 | 柄多长、多粗、往下垂多少 |

## 5. 给玩法留的口子

| 接口 | 作用 |
|---|---|
| `createNet()` 上的 `object` | 加在场景根上 |
| `place(x, y, z, hx, hz, stretch, rock)`、`hide()` | 见第 4 节 |
| `depth` | 网兜多深。现在没有人读它：`scoop.js` 用的是自己的常量 |
| `createScoop()` 上的 `begin`、`step`、`stop` | 见第 3 节 |
| `x, y, z`、`phase`、`handleX`、`handleZ` | 读。圈的中心、走到哪一段、柄朝哪 |
| `dropped`、`fishX, fishY, fishZ`、`landing`、`landedSpeed`、`caught` | 读。鱼脱钩了没有、它的嘴在哪、是不是这一帧落网、落网多快、是不是已经在网里 |
| `stretch`、`rock` | 读。网兜拉多长、晃多少，交给 `net.place` |

## 6. 还没做

- 我只在桌面的截图里看过：它从旁边进来、鱼落进去、被端起来、出画面。
- 没有拿网的手。
- 网兜是整体拉长和整体摆的，不会被鱼顶出形状。鱼在里面是头朝上立着甩的，没有蜷在兜底。
- 网不沾水，进出水面没有反应。
- 网是不透明的线，一个像素宽，没有抗锯齿。

## 7. 改的时候

- 想改网走的路、快慢、从多远进来：只改 `scoop.js` 的常量。
- 想改网的外形：只改 `net.js` 的常量和 `BAG` 表。
- 想改网从哪一侧来、鱼吊多久以后叫网：在 `catch.js`，见 [PLAY.md](./PLAY.md) 第 10 节。
- 改完在 Node 里跑 `scoop.js`，20 到 120 帧各一遍：落网的速度、圈沉多少、网走的时间应当一样；鱼每帧的位移在脱钩和落网那两帧不能跳。再在页面里对着网截几帧。
