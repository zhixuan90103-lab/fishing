## 1. 一句话

鱼往哪跑是它自己的事，我们事先不知道。我们能做的只是牵制：线和竿把它拴住，它每一窜都被线限制成线允许的那一部分。鱼带着线在水里到处换位置，就是它在乱跑、我们在牵着的结果。

## 2. 规则

### 鱼想往哪去

- **它自己挑，带随机，中途会变。** 没有一条规则读竿在哪。
- **它要的是深水和开阔处，离岸越远越好。** 每一冲都是斜着往外，朝着竿游是极少数。躲开竿说的是远近，不是左右：左外和右外一样是在远离竿。
- **不走笔直。** 每一窜都带侧向。
- **往哪一侧，主要看这时鱼头朝哪。** 它不能原地翻身，所以起冲顺着头走：头明显朝左时八成往左外去，头正对着竿或正背着竿时五五开。
- **鱼头朝哪是线带成的。** 被顶住的鱼会被停住、头被拽向竿尖。玩家牵制它的全部就是这个：鱼往右冲，玩家往左拉到僵持，鱼头被带向左，它缓过来就朝左外冲，玩家得换到右边去压。它在一个范围里来回，玩家看得到它游，手上也一直有事做。
- **剩下的是它自己的。** 它有自己想待的地方：钩住时抽一个方位，离那里越偏越可能往回走，所以来回摆的中心每条鱼不一样。一冲的途中它还可能换边，多数时候接着走原来那一侧。
- **近岸待不住。** 被带到跟前它不肯安静，缓回来一点力气就再冲：这是眼看到手又冲出去的那一下。
- **可以往水下扎。** 远处扎得深，近处扎不下去。不做跳出水面。
- **很少朝钓手这边窜。** 这时线一下子松了，要赶紧收。气力足时才有。
- **有边界。** 它始终在钓手前方的扇形里，到了边折回来（离抛投方向 36°，掉头时会多冲出去一些，最远 50° 以内）。

试过不行的：按竿在哪一侧掷骰子，七成往另一侧。竿放在一边不动，它每一冲都往同一边去；把鱼头带过来，在它下一步上看不出结果。

**和上面对不上、还没做的**（2026-11-20）：

- 场景里没有海底。"深水"现在就是离竿尖远，近岸待不住用的也是这个距离。
- 鱼想往外，但多数时候走不出去。小鱼的力小于渔轮顶得住的力，线放不出去，整场都在抛投的距离以内；大鱼带线时九成的移动也是横着的，只有头一冲走得远。要让鱼明显往远处去，得让带线的那几冲斜着往外，或者让小鱼气力足时也带得动线：后一条会推翻"小鱼不带线"，还没定。
- 往石头里钻没有做：线不碰石头，钻进去没有后果。
- 它想待的方位是抽的一个左右偏角，不是远处的一个点。

### 它实际走成什么样

由线这条约束决定，不另填角度：

| 线的情况 | 鱼实际的走法 |
|---|---|
| 线放得出去（它的力比出线点大） | 往它想去的方向走，线被带出去，斜着出去 |
| 线放不出去（小鱼，大鱼累了，或者被顶住） | 往外走不动，贴着线够得到的那道弧，往它想去的一侧滑 |
| 介于两者之间 | 又往外又往侧 |

我们能改的只有约束：竿尖放在哪、线收多紧、顶不顶。

### 没出力时

歇着、力竭的鱼是随动的：线牵它往哪它往哪，没有自己的转折，也没有自己的横向漂动。

它也不是一点力没有。鱼自身有分量，被拖动还有阻力，所以线上始终有东西。"歇的力"改成按体型算的水里的分量，出水时连续变成全重。

歇着时可以加一些身体上的甩动，只是动画，不进规则、不改线上的力：歇着"甩头的顿一下都没有"仍然是玩家知道能收了的信号。

### 从没出力到出力

划弧掉头，像汽车掉头，或者被线牵着转过去。不原地翻面。那一下线先松一松再猛地绷紧，留着：这是"它又冲了"的信号。

### 鱼自己的属性

每条鱼的数分三层：品种和体型的基数；每条鱼自己的底子（力气、速度、耐力、恢复、性子，出场时各抽一次，以后一直是它的）；遛的过程里在变的状态。同样大小的两条鱼不一样，不是完全固定的。喜好和饥饿也是它的属性，咬口那一块用，之后加。

它有两个槽。**爆发力**是一冲用的：冲的时候掉，用完就停；歇着涨，涨到它忍不住就再冲。**气力**是整场的：只降不怎么回，它决定冲的力还剩多少，也决定爆发力最多能缓回多少。没有时钟：歇多久看它恢复得快不快、性子烈不烈、气力还剩多少、这时线有没有拖着它。

### 反方向牵制有回报

一冲什么时候结束，不看时钟，看它这一冲的爆发力用完没有：

- 它顶着线实打实地使劲，这一冲的力气花得快；带着线轻松跑，花得慢。
- 所以牵制住它（竿带向反方向、线绷紧、顶住），这一冲更短、丢的线更少、它累得更快。不牵制，这一冲拖得长，线被带走一大截。
- 气力仍然按它自己使的劲来掉（[CHAIN.md](./CHAIN.md) 第 7 节），不是按它受的力。变的只是"顶着线"和"带着线跑"有了区别。

### 看得出它往哪去

主信号是线切水，水花是辅：

- **线入水的那一点在水面上划着走**，带出一道 V 形水纹，尖朝它去的方向。鱼在深处时水面上主要就是这个。（V 形的贴图做了以后 2026-11-19 拿掉了，现在只有下一条的小水花。）
- **线带出的小水花。** 线切水够快才有，速度不够没有。
- **鱼越接近水面，水花越大**，带朝向：前面尖、后面散。鱼在活动时才有，歇了就停。
- 它和竿的弯、手的颤是同一组信号，一起来一起停。

| 现在 | 改成 |
|---|---|
| 线拉住它时横向速度只留三成（`course.js` 的 `HELD_ACROSS`） | 线拉住它时沿着弧往想去的一侧滑 |

| 起冲时头朝着竿就原地翻身（`fight.js` 的 `FLIP_KEEPS`，线调硬时加的） | 划弧掉头，线松一下的那一下留着 |

| "歇的力"是表里填的数 | 按体型算的水里的分量 |
| 冲多久、歇多久按随机的时钟走（`RUN_FOR`、`REST_FOR`） | 一冲按使的劲结束；歇多久待定 |

| 歇着时身体几乎不动 | 加一些不进规则的甩动 |

## 4. 分几步做

每一步做完都过 `npm run check`，新的行为加检查，量出来的数写回 [PLAY.md](./PLAY.md)。

1. **鱼的方向和约束。** 线拉住时沿弧滑；被牵住也会换边；偏向远离拉力的一侧（2026-11-20 改成顺着鱼头，见第 2 节）；歇着完全随动；起冲改回划弧；歇的力换成水里的分量；往下扎。验：线放不出去时它的位移主要是横的；竿在一侧时往另一侧窜的比例；挂着鱼时线真松掉的时间；每档鱼遛多久。
2. **一冲按使的劲结束。** 验：同一条鱼，顶住和不顶，一冲各多长、各丢多少线、各累多少。
3. **看得出它往哪去。** 线切水的纹和小水花，近水面时的水花。先解决水花同时只能放一次。验：页面里对着截图看；水花只在鱼活动时有。
4. **朝钓手窜。** 单独做，很少出现。验：出现的比例；线松多久；握竿的手欠着的那段在这时一下子补上。

## 5. 记下、以后再定的

- **咬口。** 之后加，见 [PLAY.md](./PLAY.md) 第 14 节。
- **跳出水面。** 暂时不做。
## 6. 几个数的起点

都是起点，真机上试了再改。

| 是什么 | 起点 |
|---|---|
| 鱼头明显朝一侧时，往那一侧起冲的可能 | 八成 |
| 一冲途中换边时，接着走原来那一侧的可能 | 八成 |
| 离它想待的地方偏到边界那么远时，往回走多出的可能 | 三成 |
| 朝钓手窜占所有窜的比例 | 约十五次里一次，气力过半才会 |
| 每条鱼的底子在基数上浮动 | 力气、速度、耐力上下一成半，恢复上下两成多 |
| 边界 | 离抛投方向 36°（2026-11-20，原来 40°） |
| 近岸时少缓回几成就再冲 | 到跟前 3 米以内少四成半，9 米以外不受影响 |
