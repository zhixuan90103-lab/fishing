# 饵

状态：已实现。饵是物料：一只带三本钩的小鱼形拟饵，会挂在线上荡、会飞、会被线在水里拖着游；线收到头时固定在竿尖。它不知道什么时候抛、什么时候收。  
抛投和收线的规则在 [FISHING-REQUIREMENTS.md](./FISHING-REQUIREMENTS.md) 第 5 到 7 节，谁在驱动它见 [PLAY.md](./PLAY.md)。线见 [LINE.md](./LINE.md)。

## 1. 分层

| 文件 | 回答什么 |
|---|---|
| `src/shore/lureMove.js` | 饵的身体怎么动：位置、速度、鼻尖朝哪、背朝哪，以及固定、挂、飞、拖四种动法。不引 Three，可以在 Node 里跑 |
| `src/shore/lure.js` | 模型，以及把它摆到一个点上、鼻尖朝一个方向 |

数据只往一个方向走：玩法每帧选一种动法 → `lureMove` 算出位置和鼻尖的朝向 → 玩法把位置交给线的远端，把位置和朝向交给 `lure.place`。`lureMove` 不知道模型，`lure.js` 不知道它为什么在那里。饵没有系在任何东西上，线的远端和饵在同一个点，是因为玩法把同一个位置交给了两边。

## 2. 不能破的规则

**饵不瞬移。** 从竿尖到落点是飞过去的，从落点回来是被线拖回来的，出水以后是挂在线上荡回竿尖的。几种动法之间换的时候位置不变。线收到头以后它固定在竿尖（`hold`），不再是挂着的重物，原因见 [PLAY.md](./PLAY.md) 第 3 节。

**饵在水里不自己游，只会往下沉。** 线被收短或竿尖被带远，线被拉长了，饵才被拖向竿尖；拖得多快由线的拉力和水的阻力定。线一松它水平方向就停住，然后靠自己的重量往下沉。

**沉的时候往不往回靠，看线给不给。** 线长不变，下沉的饵是被一根定长的线吊着的，会朝竿这边划一道弧，大约荡回一个水深那么远；这是真实钓鱼里线挡关着的张力下沉。线跟着放长，它就在原地竖直沉下去，是线挡开着的自由下沉。`tow` 每帧报出 `sank`：光是下沉让饵离竿尖远了多少。给不给这段线是玩法的事：现在松着手就给，见 [PLAY.md](./PLAY.md) 第 3 节。

**帧率不改变结果。** 飞和拖按整帧精确积分，落水的那一刻解到帧的中间。挂用固定步长 1/240 秒。

## 3. 动（`lureMove.js`）

调用的人每帧选一种：

| 动法 | 什么时候用 | 怎么动 |
|---|---|---|
| `hold(x, y, z)` | 线收到头 | 固定在这个点，速度清零。点怎么动它就怎么动，不会荡。鼻尖不动它，由 `upright(dt)` 转到朝上 |
| `hang(dt, tip, lastTip, length)` | 饵被提出水面以后，到收到头之前 | 一个重物挂在一段线上。线只管不让它离竿尖比线长更远。竿尖一动它就荡 |
| `launch(reach, dirX, dirZ)` 然后 `fly(dt, braking)` | 抛出去以后 | 抛物线。`launch` 按落点距离解出初速。`braking` 为真时前进的速度很快衰减，饵在原地落下。到水面的那一帧返回 `true` |
| `tow(dt, tip, length, taken, stiffness)` | 饵在水里 | 线被拉长多少、这一帧收了多少线，算出饵被拖向竿尖多远。没人拉它时按自重下沉，拉得越快沉得越少；被拉着时顺着线往上走，但不浅过 `RUN_DEPTH`；靠近竿尖下方时完全交给线把它带上来 |

除了 `hold`，每帧动完以后调 `point(dt, tip, swimming)`：鼻尖转向竿尖，也就是顺着线。`swimming` 为真时比线更平，因为水里的饵是横着游的。固定在竿尖时调 `upright(dt)`：鼻尖按同样的快慢转到正朝上，`dt` 给 0 是一步到位，只在最开始用。

**背是记着的，不是每帧现算的。** 饵挂在线上时鼻尖正朝上，这时"背尽量朝上"没有答案，每帧现算的话鼻尖稍微一晃背就翻半圈。量到过提鱼时一帧转 175°。现在 `lureMove` 带着一个 `back` 向量：鼻尖转，它跟着转，不绕鼻尖打转；鼻尖越平，它越快地转回朝上（`UPRIGHT_RATE`），鼻尖竖着时不管它。改完同样的量法，提鱼时一帧最多 0.4°，整竿里最大的是刚甩出去那几帧的 16°，那是鼻尖自己在转。

落水后不动它：1 秒沉到约 0.6 米，4 秒 1.6 米，8 秒以后停在约 2.3 米。这时按住以 1.2 米/秒收，它顺着线上来，2 秒回到 1.7 米，之后保持在 0.3 米上下游回来。20、60、120 帧下深度相差不到 1 厘米。

收线时竿上的张力是饵的阻力：速度 × `WATER_DRAG`。匀速 1.2 米/秒时约 0.4 牛。

| 常量 | 值 | 管什么 |
|---|---|---|
| `AIR_LOSS` | 1.2 /秒 | 挂着的饵在空气里荡的时候速度掉多快。调大停得快 |
| `WATER_LOSS` | 7 /秒 | 同上，饵在水面以下时 |
| `LAUNCH_ANGLE` | 28° | 出手的仰角。调大抛得高、飞得久 |
| `BRAKE_RATE` | 5 /秒 | 线被按停以后前进的速度掉多快。是缓缓停下再落，不是撞墙 |
| `WATER_DRAG` | 0.35 牛/(米/秒) | 把饵在水里拖动要多大的力。调大收线时竿弯得更深，饵跟线跟得更慢 |
| `SINK_SPEED` | 0.35 米/秒 | 没人拉它时下沉多快。10 克的沉水米诺。调大沉得快 |
| `SINK_FLOOR`、`SINK_EASE` | −2.4、0.5 米 | 最深沉到哪，离它多远开始慢下来。是缓缓停住，不是撞到底 |
| `PLANE_SPEED` | 0.9 米/秒 | 被拉到这个速度就不再下沉。慢于它时按比例沉 |
| `RUN_DEPTH`、`RUN_RATE` | −0.4 米、3 /秒 | 被拉着时最浅游到哪，冒上来以后多快压回去。不让它贴着水面跑 |
| `NOSE_RATE` | 10 /秒 | 鼻尖转向线的快慢 |
| `NOSE_LEVEL` | 0.25 | 在水里时鼻尖的斜度是线的几成。0 是完全水平 |
| `UPRIGHT_RATE` | 7 /秒 | 鼻尖放平时背转回朝上的快慢。鼻尖越陡越慢，竖直时是 0 |
| `DEPTH_NEAR`、`DEPTH_FAR` | 1.5、4 米 | 离竿尖正下方比 `DEPTH_FAR` 远时自己沉、自己守深度，比 `DEPTH_NEAR` 近时完全交给线 |

`swum` 是饵在水里游过的水平距离，给模型摆身体用。

## 4. 模型（`lure.js`）

9 厘米的米诺，代码建模，没有外部资源。局部坐标：原点是鼻尖的系线处，+Z 是鼻尖朝的方向，身体沿 −Z 往后，+Y 是背，钩在 −Y。

- 身体是一条轮廓车出来再压扁的，背深腹浅用顶点色。
- 尾鳍是一片三角。三本钩是腹下三段弯钢丝。
- `place(x, y, z, nx, ny, nz, swum, bx, by, bz)`：系线处放在这个点，鼻尖朝这个方向，背朝 `(bx, by, bz)`，就是 `lureMove` 的 `back`。身体绕鼻尖左右摆，摆到哪由 `swum` 定，所以游的时候摆，停下就不摆。

| 常量 | 值 | 管什么 |
|---|---|---|
| `LENGTH` | 0.09 米 | 鼻尖到尾柄 |
| `HALF_HEIGHT`、`HALF_WIDTH` | 0.011、0.0065 米 | 最粗处的半高和半宽 |
| `OUTLINE` | 表 | 身体轮廓，`[往后多远, 多粗]`。改体形就是改它 |
| `WIGGLE_EVERY` | 0.16 米 | 每游这么远摆一个来回 |
| `WIGGLE_ANGLE` | 0.22 弧度 | 摆多大 |

## 5. 给玩法留的口子

| 接口 | 作用 |
|---|---|
| `createLureMove()` 上的 `hold`、`upright`、`hang`、`launch`、`fly`、`tow`、`point`、`place`、`gap` | 见第 3 节。`place` 只放位置，`gap` 量到一个点的直线距离 |
| `impact` | 读。上一次碰到水面时的速度，米/秒。水花的大小用它 |
| `back` | 读。背朝哪，单位向量，和鼻尖垂直。交给 `lure.place` |
| `sank` | 读。上一次 `tow` 里光是下沉让饵离竿尖远了多少，米。线放长这么多，饵就竖直沉 |
| `x, y, z`、`vx, vy, vz`、`nose`、`swum` | 读。位置是世界坐标。`nose` 不保证是单位长度，`lure.place` 自己归一 |
| `createLure()` 上的 `object`、`place`、`length` | 见第 4 节。`object` 加在场景根上 |
| `createLure()` 上的 `show(yes)` | 线上有没有饵。鱼把线挣断、带着饵走了以后玩法调 `show(false)`，回到空杆再 `show(true)` |

咬口时鱼把饵含住、钩住以后饵跟着鱼走，都是玩法不再调这几种动法、改成自己给位置。不要在 `lureMove.js` 里写"被咬了"。

## 6. 还没做

- 游动时在水面带出的纹。落水有水花（[SPLASH.md](./SPLASH.md)），之后水面上读不出饵在哪。
- 饵的重量不压竿。固定在竿尖时竿不会因为它多垂一点。`rod.setTipLoad` 现在改重量时不再让竿重新落位，要接可以接了。
- 飞行时没有空气阻力，也不受风。
- 出水以后是直接当成挂着的重物，水面没有反应。
- 9 厘米的饵在十几米外不到几个像素。要不要放大显示还没定。
- 只有这一种饵。

## 7. 改的时候

- 想改饵怎么飞、怎么荡、在水里跟线跟得多紧、鼻尖转多快：只改 `lureMove.js` 的常量。
- 想改外形：只改 `lure.js` 的常量和 `OUTLINE`。
- 想改抛多远、收多快、什么时候算收完：不在这里，在 [PLAY.md](./PLAY.md)。
- 改完在 Node 里跑 `lureMove.js`，见 [CONVENTIONS.md](./CONVENTIONS.md) 第 7 节。
