## 1. 定位

竖屏 WebGPU 钓鱼壳：能 dev、能 build、能真机、能震动，桌面预览接近手机/Pad。岸边水面、鱼群、鱼竿、鱼线、饵、水花、抄网和手机瞄准已经接上，都是物料。玩法以 [FISHING-REQUIREMENTS.md](./FISHING-REQUIREMENTS.md) 为准，写在 `src/play/`：一竿能走到头（甩出、落水、长按收线，鱼游来咬上，带着线冲，耗到没力收到身边，提出水面落进抄网），鱼分小、大两档，没有人派鱼（饵边的鱼自己决定，远了补 1 到 10 条），咬口分四种、钩在嘴里时抬杆才钩住，冲的时候按住是硬顶，线不会断，线松久了会脱钩，见 [PLAY.md](./PLAY.md)。

## 6. WebGPU 与水面

水面外观已定。下面的数是启动默认值，写在 `src/shore/startShore.js`。设置面板只用于当次试看，不要把试出来的另一组再写回去，除非明确要求改默认。

| 项 | 值 |
|----|-----|
| 天空 | `rustig_koppie_puresky_4k.exr`（Poly Haven，CC0）：深蓝的天，几朵小云，太阳高 28 度。2026-11-25 换的，在 `startShore.js` 里用 `params.hdri` 指定。存的是原图亮度除以 2（水面库读入时乘回来）。原来那张 `kloofendal_48d_partly_cloudy_puresky_4k.exr`（正午，低处一圈白云）还留在目录里 |
| 雾色 | `#95aac6`（红绿蓝 149、170、198，2026-11-25 在面板上调定的；最早 `#bdc7d1`） |
| 雾起始 / 结束 | 30 / 234（最早 0 / 110） |
| 风速 / 涌浪 / 翻卷 | 0.8 / 0 / 0.02 |
| 白沫 | 0.12 |
| 粗糙 / 透光 / 折射 | 0.2 / 0.22 / 1.32 |
| 曝光 / 太阳 / 泛光 | 0.61 / 0.37 / 0.012，自动曝光关 |
| 浪高 `waveScale` | 0.22（不在滑条上。低风速的 JONSWAP 是短碎浪，靠它压平） |
| 镜头 | `(0, 1.7, 2)`，yaw 100°，pitch −10°。它在离岸 47 米的海面上方，顺着海岸线看；当作站在船上，船没有画 |
| 钓鱼那片水的深度 | 4.8 到 6.5 米（`world.js` 的 `SEA_DEPTH` 5.5；2026-11-24 以前 3.3 到 4.6 米，同一天先试过 8，下面四米没有东西会去，改回 5.5）。岸线和岸边那两块出水的石头没有动 |

- Three **0.186.1**（`@types/three` 0.187.0）。0.186.1 的类型包没有发布。
- 岸边：`startShore` 建 `WebGPURenderer`。无 `navigator.gpu` 或后端不是 WebGPU → `showFatal`。
- 最终像素在 `#shore-view`。分辨率是设计尺寸 × min(dpr, 2) × `renderScale`。阴影贴图 2048。
- 海浪是三层 256² FFT（约 250 m / 37 m / 7.3 m）。改风速、涌浪、翻卷会 `ocean.rebuildSpectrum()`。
- 雾混在水面着色器里，按视线仰角和距离；天空脚下也混同一种雾（2026-11-25，`waterMaterial.js` 的 `makeHazedSky`，接在 `scene.backgroundNode` 上）：地平线上全是雾色，往上到大约 6 度就没有了，所以远处的水、雾、天在地平线上是同一个颜色，没有线。雾的颜色七成取那个方向地平线上的天空自己的颜色，三成取设置里的雾色。雾随距离先快后慢：从 1.7 米高看出去，100 米以外全挤在地平线下一度以内，匀着加就只是一条线。往下看时雾不起作用，浅水仍是折射和吸收。反射里天空占 0.5，另一半是深水色 `(0.02, 0.10, 0.18)`。天空 HDRI 高处保持清晰。
- 陆地在 +z，海在 −z。没有传感器时拖画面改 yaw/pitch，并写回设置滑条。真机上视线和竿由手机姿态决定，设置面板的「镜头回正」把手机此刻的姿态当成默认视线，见 [PHONE-LOOK.md](./PHONE-LOOK.md)。
- 资源在 `public/assets/`。代码许可在 `src/shore/minamo/LICENSE`（代码 MIT，Poly Haven 资源 CC0）。鲷鱼模型是 CC BY，见 [CONVENTIONS.md](./CONVENTIONS.md) 第 5 节。
- 禁止 `setSize(innerWidth, innerHeight)` 跟窗走。
- 水对碰它的东西的反应见 [SPLASH.md](./SPLASH.md)，分两样。溅起来的水（水花、水纹的水珠）是放在海面上方的几何体，不算改水面；它半透明，所以不在主场景里，在水面之后单独画的 `onWater` 场景里，半透明的东西放进主场景会在水面上留洞。水面自己的起伏（涟漪）接在水面材质的 `ripples` 上，只加高度和倾斜，上表的数没有动。还没做：水下的气泡。
- 岸边鱼群已接上，规范在 [FISH-SCHOOL.md](./FISH-SCHOOL.md)。游动在 `src/fish/` 下分层，不写进水面着色器。玩法通过 `take` / `giveBack` 取鱼和放回，用 `mouth` 读鱼嘴的位置，规则不写进鱼群。
- 鱼竿、渔轮和鱼线是代码建模，见 [ROD.md](./ROD.md) 和 [LINE.md](./LINE.md)。竿挂在镜头上，线加在场景根上。每帧先 `shoreSchool.update`，再 `fishing.update`、`applyPhone`、`line.brace`、`rod.update`、`line.update`、`fishing.follow`。饵和玩法见 [LURE.md](./LURE.md) 和 [PLAY.md](./PLAY.md)。

## 7. Haptics

接线规范：[HAPTICS.md](./HAPTICS.md)

真源：`plugins/native-haptics/`  
JS：`src/utils/haptics.ts`（`registerPlugin('AdvancedHaptics')`）  
注册链路（Capacitor 8 真机已验通）：

```
SceneDelegate.rootViewController = BridgeViewController()
  → capacitorDidLoad
  → registerPluginInstance(AdvancedHapticsPlugin)
```

`ios:bootstrap` 会拷 Swift、改 storyboard、**改 SceneDelegate**、补 pbx。只 `cap:sync` 不够。

只改 storyboard **不够**：Capacitor 8 用 SceneDelegate 直接 `CAPBridgeViewController()`，会绕过 storyboard，HUD 出现 `plugin: false`，按钮无震。

Swift **没有** `prepare`；引擎在 `load()` 启动。UIKit 反馈在主线程触发。验收用 HUD **点我震动**（`impact`）和状态行 `plugin: true`。  
业务节奏（具名事件、cooldown、开关）写在游戏层，不要改插件除非新增原生方法。  
玩法现在在哪几处震：每一口拽的那一下、钩住、脱钩、甩头的顿、出线和收线的咔咔、线被带光、到身边、出水、落网、网里每甩一阵、网出画面。表在 [PLAY.md](./PLAY.md) 第 11 节，咔咔的节奏在 `src/play/reelClick.js`，甩头的在 `src/play/thump.js`。
