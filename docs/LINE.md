# 鱼线

状态：已实现。线是物料：它从渔轮出发，穿过导环，从竿尖出去，连到远端；会松会绷，绷直了能把竿拉弯。远端和线长由玩法给，见 [PLAY.md](./PLAY.md)；远端上挂的饵见 [LURE.md](./LURE.md)。  
咬口、出线、拔河的规则不在这里，在 [FISHING-REQUIREMENTS.md](./FISHING-REQUIREMENTS.md)。做法的来源见 [LINE-RESEARCH.md](./LINE-RESEARCH.md)。竿见 [ROD.md](./ROD.md)。

## 1. 分层

| 文件 | 职责 |
|---|---|
| `src/shore/lineCurve.js` | 两端之间的线是什么形状。一串模拟出来的点：在空中下落，入水以后被水拖慢、慢慢下沉。只管画，不管力。不引 Three，可以在 Node 里跑 |
| `src/shore/line.js` | 把线画出来，并用它把竿尖系在远端上 |
| `src/shore/rod.js` 的 `linePath` | 线在竿上经过哪些点：渔轮的导线轮，然后是每个导环，最后一个是竿尖 |

`src/shore/startShore.js` 只负责创建、每帧在 `rod.update` 之后调用 `line.update(dt)`。

## 2. 规则：力只认两个量，形状才模拟

线要回答两件事，分开做：

- **拉得多紧**不模拟。它只由下面两个量和竿尖的位置直接算出来，同样的数永远是同样的张力。竿弯多深、出不出线、手多吃力都读它。
- **画在哪**是模拟的（第 3 节）。线有过去：它有多松是发生过的事留下的，被拉直也是一个过程。模拟出来的形状只用来画，不反过来改张力。2026-11-19 改成这样；原来形状也只由这两个量定，画出来的只能是规定好的样子。

外面只给两个量：

| 量 | 接口 | 现在谁在给 |
|---|---|---|
| 远端在哪 | `setEnd(x, y, z)` | 玩法。就是饵的位置；挂着鱼时饵在鱼嘴里，也就是鱼嘴的位置 |
| 竿尖以外放出多长 | `setLength(米)`，或 `tighten(余量)` | 玩法。飞行时跟着饵放，收线时变短 |

竿尖的位置线自己从竿上读。

**余线** = 放出的长度 − 竿尖到远端的直线距离。`line.slack` 读它。

- 余线大于零：线是松的，不拉竿。它垂下来、落水、下沉，见第 3 节。
- 余线为零：线刚好绷直，是一条直线。
- 余线小于零：两端的距离比线长。线被拉长了这么多，是一条直线，并且拉竿尖。

**竿尖最多被拉到和线同向。** 线在正前方时，再用力竿尖也只是指向远端，不会折过头；线从侧面来，竿才会弯成深弧。算法在 [ROD.md](./ROD.md) 第 5 节。

**张力不是填进去的数，是从上面两个量和竿尖的位置得出来的。** 线只在被拉长时才有力，拉长多少就按线的软硬出多少力，沿着线指向远端。竿尖被拉过去，竿就弯；竿弯了，竿尖离远端近了，拉长得少了，力也小了。两边在某个弯度上平衡。`line.tension` 读这个力。

所以：

- 远端固定、线绷直时，把竿抬起来或带向旁边，竿尖想离远端更远，线不让，竿就朝着线弯。放回去，竿弹直。
- 竿尖靠近远端，线松下来，竿上没有力。
- 把线收短（`setLength` 变小），或者远端往外走（`setEnd` 变远），张力升高，竿弯得更深。玩法就是这样拉竿的：收线是改线长，鱼冲是改远端。

**远端是两种东西里的一种。**

- 一个地方，有东西把它留在那：水里的饵，鱼的嘴（`setEnd`）。线被拉长就拉竿。
- 一个挂在线上的重物：出了水的饵，和钩上的鱼（`carry`）。线是提着它的那样东西，它的重量经过线压到竿尖上，它也被线和竿尖带着荡。重物和竿尖互相拉着，所以由竿在自己的细步长里带着它走（[ROD.md](./ROD.md) 第 5 节），线每帧把它交给竿、再把它到了哪读回来当远端。

**线挡开着的线不拉。** 空杆时饵收在竿尖、饵在飞，这两段线是随便出的，拉不上力。现在是玩法用 `setTied(false)` 说的；等渔轮成了自己的一样东西（[CHAIN.md](./CHAIN.md) 第 6 节第 4 段）这个开关就没有了。原来饵被提出水面、鱼到了身边、线断了以后也用它，2026-11-19 都去掉了：挂着的重物走上面第二种，断了的线头在水里照常被线拖着走。

张力到多大算出线、到多大会断，是玩法的规则。线只报数。

改线的时候守五条：

- 力不模拟。张力只由远端、线长和竿尖算出来，不能填进去，模拟出来的形状也不许喂回去。
- 线不许被告知松还是紧，也不许按时间变松变紧。它多松只能是有原因的：落水留下的、被力拉走的。
- 从松到紧必须有过程，不能把点直接挪到直线上。
- 它不认识鱼和饵。有鱼没鱼是同一套。
- 鱼不进线的约束，被线拉住写成鱼的目标。

## 3. 形状（`lineCurve.js`）

竿尖到远端的线是一串点（49 个），每个点有自己的位置和速度。**没有人告诉它松还是紧，也没有哪一样按时间走。** 它只拿到四样：两头在哪、放出多长、线现在拉多大力。它有多松，是发生过的事留下的：

| 这时候 | 线怎么样 | 为什么 |
|---|---|---|
| 饵在飞 | 几乎是直的，被空气带出一点弧（约 15 厘米） | 饵带着线走。玩法在飞行时只多放千分之一的线（[PLAY.md](./PLAY.md) 第 6 节的 `FLIGHT_SPARE`） |
| 饵打到水面 | 多出几厘米松线 | 饵一下子停了，线没停。饵来得越快多出越多：`OVERRUN` × 落水前的速度。这是线上全部的松 |
| 饵下沉，手松着 | 松线留着不动；靠近饵的那段被饵拖下去 | 没有东西在拉它。不会自己变直 |
| 鱼咬上，或者按住收线 | 从松到直，有过程；力越大越快 | 见下面"被拉直" |
| 挂着鱼 | 直的，只按自己的重量垂一点 | 一直有力在拉 |

它不认识鱼和饵，只认远端在哪、线拉多大力。所以没有鱼的空竿收线、有鱼的遛鱼，是同一套。

**每一小步**（约 1/240 秒）：

1. **动。** 在空中的点往下落，最快 `AIR_FALL`；在水里的点被水很快拖停（`WATER_DRAG`），只剩一个慢慢的下沉 `SINK`。水不托它，也不挡它，只是让它慢下来。线在拉的时候不这样往下掉：力把它提着，只剩它自己那点重量的垂度（`PULLED_FALL`）。
2. **两头钉住。** 在一帧里匀着从上一帧的位置走到这一帧的位置。
3. **被拉直**（只在线有力时）。每个点被拉向它两个邻居的中间，拉多少是力除以拖住它的东西（`LINE_DRAG`）：弯的地方变平、摊开。整根线一起解，力再大也不会过头。这一步把线弄短了多少，松线就用掉多少，用掉的不回来。
4. **相邻两点保持间距**（来回扫 `PASSES` 遍，水里的点比空中的难挪，`WET_HOLDS`）。
5. **关在线长够得到的范围里。** 这么长的线在这两端之间，任何一点离两端连线都超不过 √(线长² − 距离²) ÷ 2。这是几何，不是规定：松线用完了这个数就是零，线就正好是直的。

**从松到紧一定有过程。** 线被拉直的快慢是"力 ÷ 拖住它的东西 ÷ 弯的长度的平方"，所以力大就快、力小就慢，但总要走几步：10 米的弯在 4.5 牛下约三十分之一秒剩三分之一，在 0.5 牛下约三分之一秒。快的时候看不清，慢的时候看得清，画出来的每一帧都是中间的样子。

**力的变化要沿着线传过去**（`PULL_TRAVELS`）。整根线感到的力是缓着跟上去的，16 米的线约十五分之一秒。鱼咬钩那一下竿会回弹，张力有一两帧掉到零；线不会因此又松下去。

**线是尼龙线。** 查到的说法是尼龙线浮着或者沉得很慢，碳线才明显下沉，PE 线浮着；没有查到每秒几厘米的实测数，`SINK` 是按"很慢"填的起点。它是 0 就是浮在水面的线，大几倍是碳线。

**真的余线是缓着画进去的**（`SLACK_SOFT`）。玩法算的线长比两端的距离长时（飞行时那千分之一，抖竿时线让的那一截），线的垂度是余线的平方根：十米的线多出一厘米就能垂下去一掌宽。报出去的余线仍然是真的。

### 量到的数

2026-11-19，`checks/rig.mjs` 的整竿，线 16 米上下：

- 飞行时线离直线最远 0.15 米。
- 落水后线上多出约 4 厘米，离两端的连线最远约 0.4 米；饵沉了 6 秒这个数没有变。
- 鱼咬上（大鱼）：0.03 秒时离直线 0.38 米，0.10 秒 0.20 米，0.17 秒 0.14 米，0.37 秒 0.06 米。小鱼：0.31、0.15、0.05、0.02 米。20 帧和 60 帧相近。
- 之后挂着鱼的整段，离直线最远 3 到 4 厘米，出现在鱼横着冲的时候：线在水里被带出一点弧。
- 单独跑线（24 米，满力 4.5 牛一下子加上去）：0.18 秒收到 2 厘米以内，任何一帧最多走全程的一半以下；0.5 牛是 0.48 秒。

### 试过不行的

- **规定形状。** 两段直线、落点一个齐拐角；再是三段（空中一段、贴水面一段、入水处一个弯）。哪里都不折角，但水面成了地板，看着是规则限制出来的。
- **一个"松不松"的开关加定时。** 玩法说松着，线就多画一截，按固定快慢加上、退掉。多画 4% 和 1.5% 都太垮；鱼咬上以后按固定速率退，2.3 秒才直，竿已经弯了线还是松的。
- **有力就不画余线，再把所有点往直线上挤。** 0.2 秒和 0.5 秒都试过，都是整根线一起缩，没有从松到紧的过程，看着是跳过去的。
- **空中的线比水里的容易拉直很多倍。** 空中那段一帧就直了，等于又是跳。现在两边用一个数。
- **整根线一次解出间距**（三对角方程）。线接近笔直时方程是病态的，落水那一帧线会甩出去几米。换回逐段来回扫。

| 常量 | 值 | 管什么 |
|---|---|---|
| `OVERRUN` | 0.0015 秒 | 饵落水时每 1 米/秒的速度多出多少米线。满力一甩约 14 米/秒落水，多出两三厘米。调大，落水后的线更松 |
| `LINE_DRAG` | 0.015 牛·秒/米² | 线被拉直时拖住它的东西：水的阻力和它在空中的惯性，合成一个数。调小，同样的力下线直得更快；调大，鱼横着冲时线在水里弯得更多 |
| `PULL_TRAVELS` | 250 米/秒 | 力的变化沿线传多快 |
| `PULLED_FALL`、`PULL_HOLDS` | 0.04 米/秒、0.05 牛 | 在拉的线只按自己的重量垂多少（16 米、歇着的鱼约一两厘米）；力到多少这个转变就基本完成 |
| `SINK` | 0.015 米/秒 | 线在水里沉多快。尼龙线：几乎浮着 |
| `AIR_FALL` | 3 米/秒 | 松着的线在空中最快落多快 |
| `WATER_DRAG` | 60 /秒 | 水把线的速度拖掉多快。调大，落到水面上的线扎下去得更浅，现在约 5 厘米 |
| `WET_HOLDS` | 6 | 调间距时水里的点比空中的难挪几倍 |
| `SLACK_SOFT` | 0.08 米 | 真的余线比它小得多时几乎不画出垂度 |
| `STEP`、`PASSES` | 1/240 秒、80 | 小步多长，每步把间距扫几遍。遍数少了线会被画长，也就显得更松 |
| `MOVED_NOT_CARRIED` | 6 米 | 一端一帧里挪了这么远，算是被换了地方，线从直线重新开始 |

## 4. 画和拉（`line.js`）

- 一条折线，世界空间。前 10 个点在竿上，后 48 段是竿尖到远端。
- 线宽固定一个像素，半透明。真的鱼线比一个像素细得多，所以不按实际粗细建模。
- **线把远端、线长和自己的软硬交给竿，力由竿算。** 接口是 `rod.setTipTether`。为什么不由线算好一个力交过去，见 [ROD.md](./ROD.md) 第 5 节"竿尖受的三样东西"。
- **线的软硬** `STRETCH_FORCE`：把线拉长到两倍要多少牛，现在是 120，接近 0.25 毫米的尼龙线。整条线的刚度是它除以线长，所以线放得越长越软，12 米时约 10 N/m。`STIFFEST` 给这个刚度封顶在 60 N/m，线很短时不让它比竿硬太多。

`createFishingLine(rod)` 返回的对象上有：

| 接口 | 作用 |
|---|---|
| `object` | 加到场景根上，不要挂在竿或镜头下面 |
| `update(dt)` | 每帧一次，在 `rod.update` 之后 |
| `setEnd` / `setLength` / `tighten` | 见第 2 节 |
| `stow(米)` | 线收到头：远端不再是世界里的一个点，而是贴在竿尖正下方这么远，线长也就是这么多。远端取的是这一帧的竿尖，甩竿时不会慢一帧。`end` 在下一次 `update` 之后有效。再调 `setEnd` 就解除 |
| `carry(重物)` | 远端是挂在线上的这个重物（`lureMove`）。竿带着它走，`end` 是它到了哪。`setEnd` 或 `stow` 解除 |
| `setTied(是否)` | 线拉不拉得上力。只在线挡开着时为否：空杆和飞行。见第 2 节 |
| `stiffness` | 现在这么长的线每拉长一米出多少牛。饵在水里被拖多快要用它 |
| `slack`、`length` | 余线和放出的长度，米 |
| `tension` | 线拉竿尖的力，牛。松着时是 0 |
| `tip`、`end` | 竿尖和远端的世界位置。饵、水花、涟漪从这里取位置 |

调节量在 `line.js` 顶部：`HANG_POINTS`（竿尖到远端画多少段，也是模拟的点数）、`COLOR`、`OPACITY`、`STRETCH_FORCE`、`STIFFEST`。

### 每帧的顺序

`rod.update(dt)` 在前，`line.update(dt)` 在后：

1. 竿按上一帧交给它的远端和线长，走完这一帧的细步长，摆好骨骼。
2. 线读导环现在的位置，画出来，算出余线。
3. 线把这一帧的远端和线长交给竿，下一帧用。

所以远端或线长的改动晚一帧才作用到竿上。竿自己的运动不受这一帧延迟影响，因为拉力是竿在细步长里按自己当时的竿尖算的。

远端在世界里。弯的积分在平滑后的镜头坐标系里，画出来的竿再被真实镜头带回去。每步开始时把远端绕镜头转进弯的那个坐标系，转完以后竿尖到远端的距离和画面上的线一样。不转的话，快速拖镜头时余线和张力会各说各的。

### 和检索纪要的出入

[LINE-RESEARCH.md](./LINE-RESEARCH.md) 把张力当成玩法直接给的量。实现里张力是从线长和两端的位置得出来的，玩法改的是这两样。这样竿和线不会各说各的：线画成绷直的时候，竿上一定有对应的力。纪要里"离散弹性杆留给竿身"那一句也没有采用，竿身用的是梁的振动，见 [ROD.md](./ROD.md) 第 4、5 节。

### 松着的线，和水下的线

**水下的那段线越深越淡**（`FADE_DEPTH`）。水下和水上一样亮的话，眼睛分不出哪一段在水里，整根线看着是贴在水面上的；饵原地往下沉，线头在画面上往下走，就被看成了饵朝竿滑过来。

线每帧把这一刻的张力也交给形状（只读）。松不松不由任何人说：原来的 `setLay` 已经拿掉。

入水点会随着线下沉往竿这边靠，这是真的。要让人读成"饵在下沉"而不是"饵朝竿滑过来"，靠的是上面那一条：水下的线越深越淡。

| 常量 | 值 | 管什么 |
|---|---|---|
| `FADE_DEPTH` | 0.45 米 | 线在水下这么深时剩约三分之一的亮度。调小，水下的线消失得更快 |

## 5. 单独看线

设置面板里原来替玩法送数的"落点距离"和"余线"两个滑条已经拿掉，远端和线长现在只有玩法在给。要单独看线的形状，在 Node 里对 `lineCurve.js` 的 `createLineCurve` 每帧调 `step`，或者在页面里甩一竿松着手看它落水、下沉。要看线拉竿：按住收一下把线收直，再把竿抬起来或带向旁边，就能看到竿被线拉弯。

## 6. 还没做

- 断了的线没有单独的样子。出线、线断、线放尽都是玩法的事：出线是玩法在张力过了出线点时把线长加上去；线断以后玩法把远端当成一个空线头，照常收回来，它在水里被线拖着，几乎没有力。线自己不知道，见 [PLAY.md](./PLAY.md) 第 3、9 节。
- 线杯上的线随放出变薄，抛投时线从线杯上放出去。收线时渔轮已经会转，见 [ROD.md](./ROD.md) 第 7 节。
- 水面按 y = 0 算，线不跟着浪起伏。刚落水的线没有被水面的张力托住的那一会儿，也没有被风吹弯。
- 线在水下不碰海底和石头。
- 线入水处的涟漪，线在水下那一段的折射和变暗。
- 竿被重新摆位（`setPose`）后是先静止、再被线拉过去，会晃一下，没有直接落在平衡的弯度上。
- 抛投时线在空中的甩动。检索纪要里留了加几段中间点的做法，只管画面，不决定出线。
- 线没有开抗锯齿，一个像素宽，远处会闪。

## 7. 改的时候

- 想改线沉多快、落水后多松、被拉直多快：只改 `lineCurve.js` 顶部的常量。换一种线就是改 `SINK`：PE 线是 0（浮着），碳线更大。改完跑 `npm run check line`，再在 20、60、120 帧下各跑一遍看线躺的地方是不是一样，画出的长度是不是等于放出的线。
- 不要把模拟出来的形状拿去算张力或余线。
- 想改线的外观：只改 `line.js` 顶部的常量和材质。
- 想让线在竿上走别的路：改 `rod.js` 的 `linePath` 和导环表。
- 不要在线里写"绷到多紧就出线"或"多久会断"。线只报余线和张力，判断在玩法那一侧。
- 想改线的软硬：改 `STRETCH_FORCE`。改完在 20、30、60 帧下各跑一遍，张力应当收敛到同一个数，不能越抖越大。
- 鱼被线拉住或挡住，写成鱼的目标朝向和速度，交给 `take` 的 `brain`，不要把鱼放进线的约束里。见 [FISH-SCHOOL.md](./FISH-SCHOOL.md) 第 6 节。
