# 鱼竿和渔轮

状态：已实现。竿是物料：现在它跟着镜头，自己有惯性、会弯。线已经接上，见 [LINE.md](./LINE.md)。还没有接玩法。  
咬口、拔河的规则不在这里，在 [FISHING-REQUIREMENTS.md](./FISHING-REQUIREMENTS.md)。这里只提供一根会动的竿和接入的口子。

7 尺（2.13 米）纺车路亚竿和 2500 号左右的纺车轮，全部用代码建模。

## 1. 分层

竿每一帧走三步。前两步只算数，只有最后一步碰模型。

| 步 | 回答什么 | 文件 |
|---|---|---|
| 握 | 手把竿带到哪：竿在镜头前的位置，以及镜头转动时它怎么落后 | `src/shore/rodHold.js` |
| 弯 | 握把动了以后，竿身怎么跟：各段落后多少，现在是什么曲线 | `src/shore/rodFlex.js` |
| 摆 | 把骨骼摆到这条曲线上 | `src/shore/rod.js` |

其余文件：

| 文件 | 职责 |
|---|---|
| `src/shore/rodBeam.js` | 竿身是一根什么样的梁：沿竿多硬、多重。启动时解一次，得到深弯曲线和各阶振动。之后不再变，除非竿尖负重变了 |
| `src/shore/rod.js` | 模型：竿身、握把、轮座、导环、骨骼。也是把上面几层串起来的唯一一处 |
| `src/shore/reel.js` | 渔轮，见第 7 节 |

`rodBeam.js` 和 `rodFlex.js` 不引 Three，可以在 Node 里跑。`rodHold.js` 只用 Three 的数学，不碰场景。`src/shore/startShore.js` 只负责创建、把竿挂在镜头上、每帧调用 `update`。

数据只往一个方向走：镜头 → 握 → 弯 → 骨骼。弯不知道镜头，握不知道竿会弯。

## 2. 三条不能破的规则

**只用位置，不求加速度。** 镜头的朝向是一帧一帧不均匀地来的。握和弯都只拿"现在在哪"去追，不对输入求两次差分。所以一帧跳多少度都不会出尖峰，也不需要硬夹加速度。

**竿不拉长，也不撞上限。** 弯曲是每一节转一个角度，不是把点横着推出去，所以竿长始终是 2.13 米。所有上限都是越靠近越硬，或者缓缓靠近，没有一处是到了就卡住。

**帧率不改变结果。** 弯用固定步长 1/480 秒。握的追赶按整帧的转动精确积分。30、60、120 帧量出来的数一样。

## 3. 握（`rodHold.js`）

竿的根节点是镜头的子节点。这一层每帧决定它在镜头空间里的位置和朝向，并报出握把在世界里的位置，给弯用。

- **安装姿态** `ROD_POSE`：竿在镜头前的位置（米）和朝向（度）。`aimUp` 是抬起，`aimSide` 是侧偏，`roll` 是绕竿身滚转。设置面板的"鱼竿"一栏改的就是它。
- **平滑。** 拖动时镜头是一步一步不均匀地转的。镜头的朝向先过两级平滑，后面的滞后和弯曲读的都是平滑后的朝向，所以这些不均匀的步子不会变成竿在屏幕上的跳动，也不会抖到竿尖。起转和急停仍然传得过去。镜头本身没有平滑，背景还是跟着拖动走。
- **滞后。** 竿追着平滑后的朝向，没追上的那一段，变成绕手的一个转角：握把以上都落在后面，手的位置不动。手握在后握把中段。滞后是相对平滑后的朝向量的，不是相对原始镜头。

| 常量 | 值 | 管什么 |
|---|---|---|
| `FOLLOW_RATE` | 16 /秒 | 追得多快。匀速转动时落后的角度约等于转速除以它，1 弧度/秒时约 3° |
| `FOLLOW_MAX` | 5° | 最多落后多少。缓缓靠近，不是撞上去 |
| `SMOOTH_RATE` | 45 /秒 | 平滑的快慢，约 45 毫秒延迟。调小更稳也更迟钝，并且会削弱竿身最快的那一阶 |
| `HAND_AT` | 0.10 米 | 手离竿尾多远。在 `rod.js`，因为它是握把尺寸的一部分 |

停下后约半秒归位。

以后手机就是鱼竿时，竿的朝向直接来自手机，要重新看的就是这一层。弯和梁不用动。

## 4. 梁（`rodBeam.js`）

竿身被切成 17 段。竿尾硬而重，竿尖软而轻，握把和轮座那一段不弯。这一层只描述这根梁，并在启动时解出两样东西：

- **各阶振动。** 最慢的三阶，空竿是 2.8、8.6、18.6 Hz。每一阶有自己的形状，以及"推竿尾"和"转握把"各能把它带动多少。
- **深弯表。** 同一根梁在竿尖受横向力，按大转角解出每一节的转角，从直到竿尖弯 72°。它回答两件事：弯到这么深时比小弯曲硬多少，以及这时每一节各转多少。力小只弯竿尖，力大弯点往下走。

| 常量 | 值 | 管什么 |
|---|---|---|
| `FREE_HZ` | 2.8 | 空竿第一阶的频率。调高，整根竿更硬、更跟手 |
| `TIP_STIFFNESS` | 1.86 N/m | 小弯曲时竿尖的横向刚度 |
| `STIFFNESS` | 表 | 沿竿的相对刚度，`[位置, 刚度]`。往竿尖掉得越陡，调性越快 |
| `DENSITY` | 表 | 沿竿的相对质量，`[位置, 质量]`。竿尖越轻，后两阶越快，竿尖跟得越紧 |
| `TIP_ANGLE_MAX` | 72° | 深弯表的尽头，对应竿尖横向偏 0.75 米、约 3 牛的横向力 |

改竿的调性就是改这两张表。竿身的总质量不用填，由 `FREE_HZ` 和 `TIP_STIFFNESS` 定出来。

## 5. 弯（`rodFlex.js`）

每一阶振动是一个有惯性的点，在世界空间里模拟。弹簧把它拉向"竿不弯时该在的地方"。握把一动，它落在后面；握把停下，它弹过去再抖回来。握把平移和重力一并算进去：竿放平时竿尖自己下垂约 6 厘米，竖起来不垂。

- **力是从握把传到竿尖的。** 第一阶是整个上半截慢慢甩。后两阶更快，负责把一下抖腕沿竿身送上去：下段先跟手走，中段跟上，竿尖最后到，再甩过头。所以同一下动作里竿的各段不同步，弯出来的不是同一条曲线按比例放大。
- **后两阶衰减得快。** 抖一下只荡一两次，剩下的是第一阶的慢摆，停手后约 1 秒收住。
- **第一阶越弯越硬**，曲线取深弯表里的那一条。后两阶在这条曲线上再给每一节加一点偏转。
- **只横着动。** 每一阶的偏移始终垂直于握把的轴线。匀速转动不产生弯曲，只有加速和减速才弯。
- **系在竿尖上的线在细步长里算。** 每一小步按当时弯着的竿尖到锚点的距离算一次拉力，所以硬一点的线在低帧率下也不会抖起来。恒定的力（`setTipForce`）和这段线可以同时存在。

| 常量 | 值 | 管什么 |
|---|---|---|
| `DAMPING` | 0.09 / 0.13 / 0.18 | 三阶各自的阻尼比。表有几项就模拟几阶 |
| `LOSS_DOUBLES_AT` | 3 m/s | 竿尖相对握把到这个速度时损耗加倍。大摆幅收得快，小抖动留得久 |
| `RIPPLE_REACH` | 0.4 | 后两阶最多能把竿尖带偏多少，按第一阶上限的比例 |
| `SUB_DT` | 1/480 秒 | 固定步长。再加更快的一阶之前要先看它够不够小 |

## 6. 模型和给玩法留的口子（`rod.js`）

- 竿的局部 +Y 从竿尾指向竿尖。局部 +Z 是下面，导环和渔轮都挂在这一侧。
- 竿身是一根 18 节骨骼的蒙皮细管。握把、轮座是套在这根轴上的圆筒。
- 9 个导环挂在最近的骨骼上，跟着竿身一起弯。
- 每帧把每节骨骼的 +Y 对准曲线上的那一段，+Z 保持在下面，所以导环不会绕着竿身转。

`createSpinningRod()` 返回的对象上有：

| 接口 | 作用 |
|---|---|
| `object` | 根节点。挂到镜头上 |
| `update(dt)` | 每帧调用一次：握、弯、摆 |
| `setPose(pose)` | 改安装姿态，`ROD_POSE` 里的任意几项。竿会立刻静止在新位置 |
| `setTipLoad(kg)` | 竿尖挂着的重量，比如还没抛出去的饵。挂 10 克时第一阶降到约 1.8 Hz，下垂约 12 厘米 |
| `setTipForce(force)` | 竿尖受到的一个恒定的力，世界空间，牛顿。只有垂直于竿身的分量让竿弯。现在没有东西调用 |
| `setTipTether(point, length, stiffness)` | 用一段线把竿尖系在世界里的一个点上。两者的距离超过 `length` 时，线按每米 `stiffness` 牛往回拉；没超过就不拉。传 `null` 解开。鱼线每帧调用它，别处不要调 |
| `tipTension` | 这段线现在拉竿尖多大力，牛 |
| `lineStops`、`linePath(out)` | 线在竿上经过的点，世界空间：渔轮的导线轮，然后每个导环，从最靠近渔轮的到竿尖。`update` 之后调用 |
| `reel` | 渔轮的三个可动部件，见第 7 节 |

`setTipLoad` 现在没有东西调用。设置面板的"竿尖负重"滑条只用于试看。

玩法只许通过这几个口子动竿。不要从外面改骨骼，也不要在弯里写"咬口时抖一下"之类的规则：那是玩法往 `setTipForce` 里送一个力。

## 7. 渔轮（`reel.js`）

2500 号左右的纺车轮。渔轮自己的坐标：原点在轮脚和轮座相接处，+Y 指向竿尖，+Z 远离竿，+X 是钓手的左手侧，摇臂在这边。主轴和竿平行。

分四个部件，每个部件是一个组，原点在它自己的轴上：

| 部件 | 包含 | 怎么动 |
|---|---|---|
| 框架 | 轮脚、轮腿、齿轮箱 | 不动 |
| 转子 `rotor` | 杯体、两条臂、线挡钢丝、导线轮 | 绕 Y 转 |
| 线杯 `spool` | 裙边、绕着的线、卸力旋钮 | 沿 Y 前后移 |
| 摇臂 `handle` | 轴、曲柄、握丸 | 绕 X 转 |

`createSpinningRod()` 返回的 `reel` 上能拿到 `rotor`、`spool`、`handle`，以及线离开渔轮的那一点 `lineRoller`。现在没有任何东西驱动它们。收线时转摇臂和转子、线杯前后往复，抛投时打开线挡，都从这里接。

尺寸集中在 `reel.js` 顶部的常量里。旋转体用 `[半径, y]` 的轮廓表车出来，改形状就是改这些点。

## 8. 还没做

- 线杯到导线轮的那一小段线。现在线从导线轮开始画。
- 超过约 3 牛的横向力现在一律停在最深的那个弯上。线绷直后把竿抬 25° 就有 2 到 2.5 牛，已经接近这个上限，接拔河时要按鱼的冲击重新定 `TIP_STIFFNESS` 或 `TIP_ANGLE_MAX`。
- 手机就是鱼竿。换的是第 3 节那一层。
- 线挡的开合。现在钢丝固定在转子上。
- 轮座的锁紧螺母和压住轮脚的护套，握把的材质。
- 细件（竿尖、导环）在远处不到一个像素，渲染器没开抗锯齿，可能会闪。

## 9. 改的时候

- 想改竿在画面里的位置、跟镜头跟得多紧：只改 `rodHold.js`。
- 想改竿的软硬、调性、哪里弯：只改 `rodBeam.js` 的常量和两张表。
- 想改抖几下、收得多快：只改 `rodFlex.js` 的常量。
- 想改外形、尺寸、导环位置：只改 `rod.js`。骨骼数变了，梁的段数跟着变，不用另外改。
- 守住第 2 节三条规则。新加的输入先变成"握把在哪"或"竿尖受多大力"，不要直接去改某一节的角度。
- 改完怎么验见 [CONVENTIONS.md](./CONVENTIONS.md) 第 7 节。只整理结构时，用同一段镜头动作把每节骨骼的世界矩阵逐帧录下来，前后应当一个数都不差。
- 动起来像不像真竿，数值判断不了，要人看。甩动的手感要等手机接上以后在真机上看。
