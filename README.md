# Fishing

竖屏 WebGPU 钓鱼。玩法的设计只有 [docs/PLAY.md](./docs/PLAY.md) 这一份：钩住的鱼在第 8 节，还没定的在第 14 节。壳来自 portrait-webgpu-base（390×844 contain、Capacitor iOS、震动插件）。镜头在离岸四十多米的海面上方，当作在船上（船没画）。现在有水面、一群会游的鲷鱼、一根第一人称的纺车竿、鱼线和一只拟饵。可以把饵甩出去、落水、长按收回来；饵在水里时饵边的鱼自己过来一口一口地咬，钩在嘴里时把手机往上一抽才钩住；钩住以后冲的时候把线带出去，耗到没力再收到身边，提出水面，用抄网兜走。鱼有大有小，大的才带得出线，每条鱼的力气、耐力、性子都有点不一样；它往哪跑是它自己的事，手里只能用线牵制它：它一冲几秒、横着窜出几米，咬钩以后一直在水面下半米多、不往深处扎；歇着收线时它被线拽着头转过来、拖到跟前，缓过劲又扭头跑；一场几轮，一轮比一轮弱；到了跟前还会再冲；冲的时候按住是硬顶，线出得慢、竿更弯，线不会断。咬口的种类和抬杆还没做。岸边水面已经定稿，先不要再改海浪、雾和曝光。

## 本地

```bash
npm install
npm run dev
npm run check    # 不用手机能跑的检查，改了代码就跑
# http://127.0.0.1:5190/
```

5190 被别的工程占用时，换一个端口，不要关掉别人的进程。应看到朝向大海的岸边，画面里有一根鱼竿，竿尖上收着一只小饵，水下有鱼群。`/fish.html` 可以单看一条鱼。右上角 **设置** 里可以调雾、水、鱼、鱼竿和镜头，震动测试在面板最下面。桌面没有原生马达。

桌面上走一竿：拖动画面对方向，按住空格约半秒再松开，饵飞出去落水；再按住空格收线，松开就停，一直收到饵回到竿尖。饵在水里时会有鱼来咬：打开设置面板，最下面"这一竿"一行出现"钩在嘴里"时按一下方向键上（或 W）就是抬杆，钩住以后按住空格遛。空格按得越久抛得越远，按键抬杆，这些只是桌面的替身，真机上看的是甩竿的力度和手机往上一抽。

## 真机

包名 `com.wangzhixuan.fishing`，主屏幕名 Fishing。不要改回模板的 `com.wangzhixuan.pwgbase.hapticstest`。

```bash
npm run ios:bootstrap   # 第一次，或改了 plugins/native-haptics
npm run cap:sync        # 只改了网页
# Xcode 选 zhixuan 的 iPhone → Run
```

`ios:bootstrap` 会把 `SceneDelegate` 设成 `BridgeViewController`。漏了这一步，真机上 `plugin: false`，点震动没有反馈。验收先看状态行 `plugin: true`，再在设置里点 **点我震动**。

## 现在有什么

- 水面外观已定，数值在 [docs/ENGINEERING.md](./docs/ENGINEERING.md) 第 6 节。三层 256² FFT 保留。天空是一张深蓝少云的（2026-11-25 换的），远处的水和天空脚下用同一种雾，地平线上没有线。水对碰它的东西有反应：砸进去起水花（一蓬白水、水珠、过后留在水面的白沫，画成几百个柔边小团）和一圈圈涟漪；线、鱼、拖着的饵走过去，身后是 V 形尾迹；水下的东西头顶只是缓涌；鱼被抬竿带到水面时四溅。水下的气泡还没有。这些都不重调整片海。
- 镜头默认 `(0, 1.7, 2)`，朝向 100°，俯仰 −10°。陆地在 +z，海在 −z。桌面拖画面改朝向。真机点「允许手机转动」后转动手机：没按住屏幕时镜头和竿一起跟，按住时镜头停、只动竿；饵甩出去以后镜头转向落点，收完再缓缓交还给手机。挂着鱼时镜头去看鱼，但始终把竿尖留在画面里：鱼冲出画面，就是该带竿把它拉回来了。手机拿回原来的姿态画面就回来，偏了用设置里的 **镜头回正**。设计在 [docs/PHONE-LOOK.md](./docs/PHONE-LOOK.md)。
- 水下有 40 条鲷鱼（另有 10 条备用的，饵离鱼群远时才从画面外游进来），每条自己拿主意，没有人指挥：只看身边的鱼，少数有想法的把别的带着走，被挤到或落单会窜一下，身体会摆、转弯会弯。设计在 [docs/FISH-SCHOOL.md](./docs/FISH-SCHOOL.md)。设置里的 **游速** 可以调。
- 镜头上挂着一根 7 尺纺车竿和渔轮，代码建模。转动镜头时整根竿慢一拍跟上，竿身有惯性：下段先动，竿尖最后到，停下后抖几下。设计在 [docs/ROD.md](./docs/ROD.md)。
- 鱼线从渔轮穿过导环，从竿尖连到饵。线几乎不拉长，是手和鱼之间的约束。松线只来自饵落水那一下，之后被线上的力一点点拉直：力大就快，但总有过程。水下的部分越深越淡。线切水够快时入水的地方在水面上拖出一道细尾迹。饵在水里时把竿抬起来或带向旁边，竿会被线拉弯。设计在 [docs/LINE.md](./docs/LINE.md)。
- 饵是一只 9 厘米的米诺。默认线收到头，饵贴在竿尖，跟着竿的动作轻轻摆。真机上按住屏幕、向前甩、松手，饵按松手时竿尖的速度飞出去 4 到 28 米，往哪飞、飞多高是手指按下那一刻镜头看的方向，镜头自己转向落点，落水时有水花；飞的途中再按住，饵就近落下。落水后按住是收线，先慢后匀速；松手饵在原地头朝下慢慢沉，这时抖竿它只窜一下、晃几下，不会被拽回来；收到头这一竿结束，可以再甩。饵在水里时没有人派鱼：离饵近的鱼自己注意到它，想吃的聚到饵边绕着，一次一条上去咬；饵离鱼群远时，从画面外游来一到十条另加的鱼。慢慢收、收一下停一下最招鱼，停着也招，一直按着快收鱼不追。咬口有轻有重，不出字，从竿尖和手里读：轻咬是轻轻一下，中咬是一拽再拖着，重咬拖得久还会再拽。钩在它嘴里的那一会儿把手机往上一抽才钩住；只收线不抬，饵会被拉出它的嘴。没钩住的抬杆会惊到饵边的鱼，正咬的那条惊得多、旁边的少，饿的留下躲一阵，不饿的跑。钩住以后竿被拉弯，鱼冲一阵歇一阵：冲多久、歇多久不按时钟，看它的爆发力用完没有、缓过来没有。它往远处和侧面窜，每一冲水面都被它搅起来。鱼群里有小鱼和大鱼，小鱼带不出线，一直按着就收得回来；大鱼有力的时候一冲线就被带出去，手里咔咔地震，按着也收不动。冲的时候竿弯得深、竿尖一下一下点头、握竿的手发颤，手里有甩头的顿；它一歇这些都停了，竿松成浅弯，这时按住才收得动。手上有几样牵制它：冲的时候按住或者把竿压低，线出得慢；逆着它游的方向带竿，它横着跑得慢；歇着收线把它的头带过来，它下一冲多半往那边去。线不会断，但线松久了它会把钩甩掉，饵留在水里接着钓；一直不收让它把线带光，鱼就丢了，要把空线收回来才能再抛。一场是几轮，小鱼两三轮，大鱼六轮上下，每一轮冲的力、冲多久、带走的线都比上一轮小一截。没力了，按住把它收到身边，它咬着饵甩着被提出水面，抄网从左边伸到它下面，它脱钩落进网里接着甩，网带着它出了画面这一竿就结束，线自己收完。设计在 [docs/LURE.md](./docs/LURE.md) 和 [docs/PLAY.md](./docs/PLAY.md)。
- 设置面板可以临时试雾、水、鱼竿的位置、镜头。面板里"这一竿"一行实时显示甩竿时竿尖的速度、饵边几条鱼、最想吃的那条多想吃多饿多惊、这一口是哪种、钩在不在嘴里、鱼的体型、线的张力、鱼的力、手指叠的力、压竿多顶多少、带竿刹住几成、钩松了几成、手多吃力、出线的速度、气力和钓到几条，调手感时看它。震动测试在面板最下面。关掉再开回到上面的默认值。
- 无 WebGPU 就明确失败，不回退 WebGL。
